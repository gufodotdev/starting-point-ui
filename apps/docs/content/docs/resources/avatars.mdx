Free avatar placeholder images for UI design, mockups, and prototypes. Every avatar is a face-cropped photo from [Unsplash](https://unsplash.com) paired with a fictional name, sized at 640 × 640 and ready to use as a profile picture in an app, a persona in a case study, or a stand-in user in a design. Click a photo to copy its image URL.

## Backgrounds

The tabs above the grid switch every avatar between three versions. Default keeps the photo's original background. Neutral removes the background and replaces it with a light gray, which gives the whole set a uniform, studio-like look. Transparent removes the background entirely and serves a PNG with real transparency, so you can place the avatar on any color or surface in your design.

## How to use them

Each image is served straight from the Unsplash CDN, so you can hotlink the URL or download the file. The URL carries the sizing parameters: change `w` and `h` for a different resolution, or lower `q` to trade quality for a smaller file.

## Make your own

Need different faces, or a looser crop? The avatars on this page were made with the [Unsplash Editor](/resources/unsplash-editor), using its face crop and background removal. It works with any Unsplash photo, so you can use it to make your own.
