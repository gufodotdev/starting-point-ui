## How it works

Unsplash photos can be edited straight through their web address: instructions in the image URL tell Unsplash how to crop, resize, and process the photo before it reaches the page. This editor writes those instructions for you as you work, so the finished image is just a link. The preview you see is the real output, and what you copy is exactly what your visitors get.

Because the edit lives in the URL, there is nothing to download, upload, or store. The link works without an account, loads fast from the same image CDN that serves every Unsplash photo, and keeps working for as long as the photo exists on Unsplash.

## What you can do

- **Crop** free-form, to a preset ratio, or to a custom one, plus rotate and flip
- **Face crop** for avatars, with adjustable framing
- **Adjustments** for exposure, contrast, highlights, shadows, saturation, and more
- **Filters**, nine presets with adjustable strength
- **Background removal**, transparent or replaced with a color
- **Export** at different sizes and quality, with a file size estimate

When you are happy with the result, copy the URL and drop it straight into an `<img>` tag, or download the file if you would rather serve it from your own host.

## Editor controls

Drag the box to move it, drag the handles to resize, scroll to zoom the selection, or draw a new box anywhere on the image. Arrow keys nudge the box, hold Shift for bigger steps.
