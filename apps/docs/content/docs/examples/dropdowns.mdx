A collection of Tailwind CSS dropdown menu examples with beautiful shadcn/ui styling. The examples are built with the library's menu components, like the [dropdown](/components/dropdown), [popover](/components/popover), and [combobox](/components/combobox), and are ready to copy into your project.

## Profile

An avatar button opens the account menu with an identity header, grouped shortcuts, and a nested submenu.

```html preview preset=lg align=top open=.dropdown
%include examples/dropdowns/profile-dropdown.tsx%
```

A profile dropdown, or user menu, puts account actions behind the signed-in user's avatar. It typically opens with the user's name and email, followed by shortcuts like profile, billing, and settings, a team section for inviting people, and a log out action at the end. The pattern lives in the top corner of nearly every app with accounts, from SaaS dashboards to storefronts.

## Notifications

A bell button with an unread count badge opens a scrollable activity feed with timestamps and actions.

```html preview preset=lg align=top open=.popover
%include examples/dropdowns/notifications.tsx%
```

A notification dropdown lets users check recent activity without leaving the page. A bell button with an unread count badge is the usual trigger, opening a compact feed of updates that users can scan and act on directly, whether that's accepting a follow request, jumping to a reply, or marking everything as read. The pattern fits anywhere users expect quick access to updates and alerts, from social apps to SaaS dashboards and messaging tools.

## Country picker

A country field opens a searchable list with flags and recent picks, filtering as the user types.

```html preview preset=lg align=top open=.combobox
%include examples/dropdowns/country-picker.tsx%
```

A country picker gives users a comfortable way to select their country from a long list. Flags make options easy to recognize, recent picks put the likely choices at the top, and typing filters the list for anyone who would rather search than scroll, with the selection submitting like any native form value. Country fields appear in checkout address forms, sign up flows, and shipping or billing settings, anywhere an app needs to know where its users are.

## Table row actions

An ellipsis button at the end of each table row opens a menu of row actions.

```html preview preset=lg align=top open=.dropdown:first
%include examples/dropdowns/table-row-actions.tsx%
```

A table row actions dropdown, sometimes called a kebab menu after its three-dot trigger, keeps a data table clean by collecting every per-row operation in one place. Each row keeps its actions a click away without cluttering the table with buttons, and destructive choices like delete can sit apart from the rest instead of exposed next to the data. The pattern runs through file managers, admin panels, and dashboards, anywhere users manage lists of records without leaving the page.
