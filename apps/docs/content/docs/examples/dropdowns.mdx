A collection of Tailwind CSS dropdown menu examples with beautiful shadcn/ui styling. The examples are built with the library's menu components, like the [dropdown](/components/dropdown), [popover](/components/popover), and [combobox](/components/combobox), and are ready to copy into your project.

## Profile dropdown

An avatar opens the account menu. Give the trigger an `aria-label` since it has no visible text.


A [popover](/components/popover) holds the notification list, since the rows are content rather than menu actions. Give the icon trigger an `aria-label`.
