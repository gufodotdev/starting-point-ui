Starting Point UI uses CSS variables for theming, and the variables are exactly the ones shadcn/ui uses. That means any shadcn-compatible theme works here unchanged: paste a theme from [tweakcn](https://tweakcn.com) or the shadcn theme registry into your CSS and every component follows. Use the **theme editor** in the top right to preview changes and export your theme.

## Convention

We use a `background` and `foreground` convention for colors. The `background` variable is used for the background color of a component and the `foreground` variable is used for the text color.

Given the following CSS variables:

```css
--primary: oklch(0.205 0 0);
--primary-foreground: oklch(0.985 0 0);
```

The `background` color of the following component will be `var(--primary)` and the `foreground` color will be `var(--primary-foreground)`.

```html
<div class="bg-primary text-primary-foreground">Hello</div>
```

## Radius

The single `--radius` variable drives the whole radius scale: `rounded-sm` through `rounded-4xl` are derived from it multiplicatively, so changing one value reshapes every component consistently.

```css
:root {
  --radius: 0.5rem; /* sharper */
}
```

## Customizing the theme

Override any of these variables after importing the library styles:

```css label="app/globals.css"
@import "tailwindcss";
@import "starting-point-ui";

:root {
  --primary: oklch(0.55 0.2 250);
  --primary-foreground: oklch(1 0 0);
  --ring: oklch(0.55 0.2 250);
}

.dark {
  --primary: oklch(0.65 0.18 250);
  --primary-foreground: oklch(0.15 0 0);
  --ring: oklch(0.65 0.18 250);
}
```

## Component-local variables

A few structural knobs live on their components rather than in the theme, so the theme stays purely shadcn. Override them on the element, with a utility or a rule:

- `--sidebar-width`, `--sidebar-width-mobile`, `--sidebar-width-icon` on `sidebar` / `sidebar-container`
- `--scrollbar-width`, `--scrollbar-thumb`, `--scrollbar-track`, `--scrollbar-radius` on `scrollbar`
- `--card-spacing` on `card`
- `--dialog-spacing` on `dialog`

```html
<div class="sidebar-container [--sidebar-width:14rem]">
```

```css
.sidebar-container {
  --sidebar-width: 14rem;
}
```

## Fonts

The library uses two font variables:

- `--font-sans` — Tailwind's default body font token. Defaults to the system sans-serif stack. Set this to use a custom body font.
- `--font-heading` — applied to `h1` through `h6` and to component titles like the card, dialog, and sheet titles. Inherits from `--font-sans` by default, so headings follow the body font unless you override it.

Override them to use different fonts:

```css
:root {
  --font-sans: "Inter", sans-serif;
  --font-heading: "Playfair Display", serif;
}
```

## Adding new colors

To add new colors, define them in your CSS and use the `@theme inline` directive to make them available as Tailwind utilities:

```css label="app/globals.css"
:root {
  --warning: oklch(0.84 0.16 84);
  --warning-foreground: oklch(0.28 0.07 46);
}

.dark {
  --warning: oklch(0.41 0.11 46);
  --warning-foreground: oklch(0.99 0.02 95);
}

@theme inline {
  --color-warning: var(--warning);
  --color-warning-foreground: var(--warning-foreground);
}
```

You can now use the `warning` utility class in your components:

```html
<div class="bg-warning text-warning-foreground"></div>
```
