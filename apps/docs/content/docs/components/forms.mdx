Use the form components together to build complete forms, like a login, a signup, or a settings page. Each [field](/components/field) lays out a label, control, and description around a native form element, so values submit with the form.

## Components

- [Field](/components/field) lays out labels, controls, descriptions, and errors
- [Label](/components/label) names a form control
- [Input](/components/input) captures single-line text, like emails and passwords
- [Input Group](/components/input-group) composes icons, text, and buttons inside one field
- [Textarea](/components/textarea) captures multi-line text
- [Select](/components/select) picks one option from a native list
- [Combobox](/components/combobox) searches a list of options, single or multi select
- [Checkbox](/components/checkbox) toggles options on and off
- [Radio Group](/components/radio-group) picks a single option from a set
- [Switch](/components/switch) toggles a setting on and off
- [Slider](/components/slider) picks a value or range along a track
- [Button](/components/button) submits the form and triggers actions
- [Button Group](/components/button-group) attaches related buttons and fields together
