Forms compose from small pieces: a [field](/components/field) lays out each label, control, and description, and the controls build on native form elements, so values submit with the form. This page shows the pieces working together and links out to each one.

## Components

- [Field](/components/field) — Structured layout for labels, controls, descriptions, and errors
- [Label](/components/label) — Accessible labels for form fields
- [Input](/components/input) — Single-line text entry for text, email, password, and other types
- [Input Group](/components/input-group) — Compose icons, text, and buttons inside one field
- [Textarea](/components/textarea) — Multi-line text input
- [Select](/components/select) — Native dropdown for choosing from a list of options
- [Combobox](/components/combobox) — Searchable option list with single and multi select
- [Checkbox](/components/checkbox) — Toggle options on and off, with card and table variants
- [Radio Group](/components/radio-group) — Pick a single option from a set
- [Switch](/components/switch) — Toggle settings on and off
- [Slider](/components/slider) — Pick a value or range along a track
- [Button](/components/button) — Actions and form submissions
- [Button Group](/components/button-group) — Attach related buttons and fields together
