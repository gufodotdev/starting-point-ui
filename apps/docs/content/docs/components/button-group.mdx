---
title: Tailwind CSS Button Group
description: Beautiful, modern button group component for Tailwind CSS. Use it to attach related buttons into one row, like a split button or a toolbar. Easily customizable.
---

Use the button group component to attach related controls into one segmented row, like a split button, a set of toolbar actions, or an input with its button. For switching between views, reach for [tabs](/components/tabs) instead.

```html preview preset=sm
<div class="btn-group">
  <div class="btn-group">
    <button class="btn btn-outline btn-icon" aria-label="Go back">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m12 19-7-7 7-7"/><path d="M19 12H5"/></svg>
    </button>
  </div>
  <div class="btn-group">
    <button class="btn btn-outline">Archive</button>
    <button class="btn btn-outline">Report</button>
  </div>
  <div class="btn-group">
    <button class="btn btn-outline">Snooze</button>
    <button
      id="bg-more-trigger"
      class="btn btn-outline btn-icon"
      aria-label="More options"
    >
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="1"/><circle cx="19" cy="12" r="1"/><circle cx="5" cy="12" r="1"/></svg>
    </button>
  </div>
</div>

<div
  class="dropdown min-w-40"
  data-sp-toggle="#bg-more-trigger"
  data-sp-placement="bottom-end"
>
  <a href="#" class="dropdown-item">Mark as read</a>
  <a href="#" class="dropdown-item">Archive</a>
</div>
```

## Usage

Add the `btn-group` class to a container and put [buttons](/components/button) directly inside it. The group removes the inner radii and collapses the shared borders.

| Class                 | Description                                          |
| --------------------- | ---------------------------------------------------- |
| `btn-group`           | Add to the container wrapping the buttons            |
| `btn-group-vertical`  | Add to `btn-group` to stack the buttons vertically   |
| `btn-group-separator` | Add to an element between buttons to divide them     |
| `btn-group-text`      | Add to a child for static text alongside the buttons |

```html
<div class="btn-group">
  <button class="btn btn-outline">Left</button>
  <button class="btn btn-outline">Center</button>
  <button class="btn btn-outline">Right</button>
</div>
```

### Nested button groups

Nest groups inside a group and they separate with a small gap. Anything groupable nests the same way, like the [input group](/components/input-group) holding the message field here.

```html preview preset=sm

  <div class="btn-group">

    </button>
  </div>
  <div class="btn-group">
    <div class="input-group">
      <input class="input" placeholder="Send a message..." />
```

### Split button

Pair a main action with a compact secondary one. Outline buttons separate themselves with their borders. For other variants, divide the buttons with a `btn-group-separator`.

```html preview preset=sm
<div class="btn-group">
  <button class="btn btn-secondary">Button</button>
  <div class="btn-group-separator"></div>
  <button class="btn btn-secondary btn-icon" aria-label="Add">
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M5 12h14"/><path d="M12 5v14"/></svg>
  </button>
</div>
```

### Button group with text

Attach static text to a control with `btn-group-text`, like a prefix or a unit.


### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. Flip directional icons with `rtl:rotate-180`. See the [RTL guide](/guides/rtl) for details.

```html preview preset=sm dir=rtl
<div id="button-group-rtl-demo" dir="rtl">
  <div class="btn-group">
    <div class="btn-group hidden sm:flex">
      <button class="btn btn-outline btn-icon" aria-label="Go back">
        <svg class="rtl:rotate-180" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m12 19-7-7 7-7"/><path d="M19 12H5"/></svg>
      </button>
    </div>
    <div class="btn-group">
      <button class="btn btn-outline" data-i18n="archive">أرشفة</button>
      <button class="btn btn-outline" data-i18n="report">تقرير</button>
    </div>
    <div class="btn-group">
      <button class="btn btn-outline" data-i18n="snooze">تأجيل</button>
      <button
        id="bg-rtl-more-trigger"
        class="btn btn-outline btn-icon"
        aria-label="More options"
      >
        <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="1"/><circle cx="19" cy="12" r="1"/><circle cx="5" cy="12" r="1"/></svg>
      </button>
    </div>
  </div>

</div>
<script>
  const translations = {
    ar: { dir: "rtl", archive: "أرشفة", report: "تقرير", snooze: "تأجيل" },
    he: { dir: "rtl", archive: "ארכיון", report: "דווח", snooze: "נודניק" },
    en: { dir: "ltr", archive: "Archive", report: "Report", snooze: "Snooze" },
  };
  window.addEventListener("message", (e) => {
    const t = translations[e.data?.lang];
    if (e.data?.type !== "sp-language" || !t) return;
    document.getElementById("button-group-rtl-demo").dir = t.dir;
    document.querySelectorAll("[data-i18n]").forEach((el) => {
      el.textContent = t[el.dataset.i18n];
    });
  });
</script>
```
