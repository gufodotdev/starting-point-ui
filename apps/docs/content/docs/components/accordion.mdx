The accordion stacks sections vertically and opens one at a time, closing the others. It is the familiar pattern for FAQs, product details, and settings groups. For a single standalone panel, reach for the [collapsible](/components/collapsible).

```html preview

    </button>
  </h3>
```

## Usage

An accordion is a group of [collapsibles](/components/collapsible) that close each other. Each section is a trigger and a collapsible that points back at it with `data-sp-toggle`, exactly as a standalone collapsible. Wrapping them in `accordion` adds the single-open rule and the accordion ARIA roles.

Per the [WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/), wrap each trigger in a heading (`h2`-`h6`) that matches your page outline. Add `accordion-trigger` to the button for the header styling and `accordion-content` to the panel body for its spacing.

| Class               | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `accordion`         | Add to the container wrapping the sections; carries `data-sp-multiple` |
| `accordion-trigger` | Add to the header button inside each heading                   |
| `accordion-content` | Add to the panel body, alongside `collapsible-content`         |

```html
<div class="accordion">
  <h3>
    <button id="section-1" class="accordion-trigger">Section one</button>
  </h3>
  <div class="collapsible" data-sp-toggle="#section-1">
    <div class="collapsible-content accordion-content">First panel</div>
  </div>
  <h3>
    <button id="section-2" class="accordion-trigger">Section two</button>
  </h3>
  <div class="collapsible" data-sp-toggle="#section-2">
    <div class="collapsible-content accordion-content">Second panel</div>
  </div>
</div>
```

## Options

### Accordion

Set each option with its own `data-sp-*` attribute on the `accordion` element.

| Attribute          | Values  | Default |
| ------------------ | ------- | ------- |
| `data-sp-multiple` | Boolean | `false` |

```html
<div class="accordion" data-sp-multiple>
```

### Collapsible

Each section's panel is a [collapsible](/components/collapsible) and takes its options; point it at its trigger with `data-sp-toggle`.

| Attribute        | Values       | Default |
| ---------------- | ------------ | ------- |
| `data-sp-toggle` | CSS selector | —       |

```html
<div class="collapsible" data-sp-toggle="#section-1">
```

## JavaScript

### Events

Each panel is a [Collapsible](/components/collapsible), so the full lifecycle (`sp-beforeexpand` through `sp-collapsed`) fires on the panels and bubbles to the accordion container.

```js
accordion.addEventListener("sp-expanded", (e) => {
  console.log("opened:", e.target); // the collapsible panel
});
```

### Methods

Each panel is a Collapsible instance; get one with `sp.collapsible(panel)`, then call its methods:

| Method       | Description                        |
| ------------ | ---------------------------------- |
| `expand()`   | Expand the panel                   |
| `collapse()` | Collapse the panel                 |
| `toggle()`   | Expand if collapsed, else collapse |

```js
const panel = document.querySelector("#my-accordion .collapsible");

sp.collapsible(panel).expand();
```

## Accessibility

The accordion adheres to the [Accordion WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) and sets the appropriate roles and properties automatically. Wrap each trigger in a heading (`h2`-`h6`) that matches your page outline, as in the examples.
