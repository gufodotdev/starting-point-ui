A stack of expandable sections where the first trigger pairs with the first panel, the second with the second, and so on.

## Basic Usage

Add `data-sp-accordion` to a container holding `accordion-trigger` buttons wrapped in headings and one `accordion-panel` per trigger. Wrap panel children in `accordion-content`. Opening a section closes the open one, and clicking an open section's trigger closes it. All ids, ARIA attributes, and pairing are handled automatically.

```html preview
<div class="accordion max-w-md" data-sp-accordion>
  <h3>
    <button class="accordion-trigger">
      Is it accessible?
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="text-muted-foreground in-aria-expanded:rotate-180"><path d="m6 9 6 6 6-6"/></svg>
    </button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">
      Yes. It adheres to the WAI-ARIA accordion pattern with all wiring done for you.
    </div>
  </div>
  <h3>
    <button class="accordion-trigger">
      Is it styled?
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="text-muted-foreground in-aria-expanded:rotate-180"><path d="m6 9 6 6 6-6"/></svg>
    </button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">
      Yes. It ships with default styles you can override with utilities.
    </div>
  </div>
  <h3>
    <button class="accordion-trigger">
      Is it animated?
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="text-muted-foreground in-aria-expanded:rotate-180"><path d="m6 9 6 6 6-6"/></svg>
    </button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">
      Yes. The height transition is animated by default.
    </div>
  </div>
</div>
```

## Multiple open sections

Add `multiple: true` so opening a section keeps the others open.

```html preview
<div class="accordion max-w-md" data-sp-accordion="multiple: true">
  <h3>
    <button class="accordion-trigger">Shipping</button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">Free shipping on orders over $50.</div>
  </div>
  <h3>
    <button class="accordion-trigger">Returns</button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">Returns are accepted within 30 days.</div>
  </div>
</div>
```

## Initially open

Add the `shown` class to a panel so it renders open on first paint, before JavaScript loads. Set `aria-expanded="true"` on its trigger so the state matches.

```html preview
<div class="accordion max-w-md" data-sp-accordion>
  <h3>
    <button class="accordion-trigger" aria-expanded="true">Open by default</button>
  </h3>
  <div class="accordion-panel shown">
    <div class="accordion-content">This section starts expanded.</div>
  </div>
  <h3>
    <button class="accordion-trigger">Closed by default</button>
  </h3>
  <div class="accordion-panel">
    <div class="accordion-content">This section starts collapsed.</div>
  </div>
</div>
```

## Options

Set options in the `data-sp-accordion` value, separated by semicolons.

| Option     | Type    | Default | Description                             |
| ---------- | ------- | ------- | ---------------------------------------- |
| `multiple` | Boolean | `false` | Opening a section keeps the others open |

## Events

Each panel is a [Collapsible](/docs/components/collapsible), so the full lifecycle (`sp-beforeshow` through `sp-hidden`) fires on the panels and bubbles to the accordion container.

```js
accordion.addEventListener("sp-shown", (e) => {
  console.log("opened:", e.target);
});
```

## Methods

Panels are Collapsible instances; control one with `sp.collapsible(panel)`:

```js
const panel = document.querySelector("#my-accordion .accordion-panel");

sp.collapsible(panel).show();
```

## Accessibility

The accordion adheres to the [Accordion WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) and sets the appropriate roles and properties automatically. Wrap each trigger in a heading matching your page's structure, as in the examples.

| Key                     | Action                                    |
| ----------------------- | ----------------------------------------- |
| `Enter` / `Space`       | Toggles the focused header's section      |
| `ArrowDown` / `ArrowUp` | Move focus to the next or previous header |
| `Home` / `End`          | Move focus to the first or last header    |
