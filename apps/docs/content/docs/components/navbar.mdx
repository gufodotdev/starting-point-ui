---
title: Navbar
description: A Tailwind CSS navbar component for top navigation, pairing your brand, menu links, and actions in a header bar across the top of the page.
---

The navbar places your brand, primary navigation, and actions in a bar across the top of the page, the most familiar wayfinding pattern on the web. Use it when the navigation is shallow enough to fit horizontally, like marketing sites, product pages, and apps with a handful of top-level sections; for deeper navigation, reach for the [sidebar](/components/sidebar) instead.

## Usage

Add the `navbar` class to a `<header>` element. The bar is a plain flex row, so its contents are up to you: typically a [brand](/components/brand), a `navbar-menu` of links, and actions on the right, but breadcrumbs, a search field, or anything else works just as well. In a menu, mark the current page's item with the `active` class.

On small screens a full menu rarely fits. A common pattern is to hide it with `max-sidebar:hidden` and provide the same links as a [sidebar](/components/sidebar) drawer: give the sidebar `sidebar:hidden` so it never renders as a desktop column, and point it at a trigger in the navbar that only shows on mobile.

| Class            | Description                                                   |
| ---------------- | ------------------------------------------------------------- |
| `navbar`         | Add to a `<header>` element to create the bar                 |
| `navbar-menu`    | Add to a `<nav>` element to create the horizontal menu        |
| `navbar-menu-item` | Add to the menu's links; `active` marks the current page    |
| `navbar-menu-underline` | Add to the menu to underline the active item            |

```html
<header class="navbar">
  <a href="/" class="brand">...</a>

  <!-- Desktop menu -->
  <nav class="navbar-menu max-sidebar:hidden">
    <a href="#" class="navbar-menu-item active">Home</a>
    <a href="#" class="navbar-menu-item">Pricing</a>
  </nav>

  <!-- Mobile trigger for the drawer -->
  <button id="nav-trigger" class="btn btn-ghost btn-icon-sm sidebar:hidden">...</button>
</header>

<!-- Mobile navigation drawer -->
<aside class="sidebar sidebar:hidden" data-sp-toggle="#nav-trigger">...</aside>
```

## Accessibility

The navbar adheres to the [Navigation Landmark WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/navigation.html): the `<nav>` element in the examples creates the landmark, and the framework sets [`aria-current`](https://www.w3.org/TR/wai-aria-1.2/#aria-current) on the active menu item automatically.

When a page includes more than one navigation landmark, the pattern says each should have a unique `aria-label`, as in the sidebar page header example above. The menu and its mobile drawer need no labels, since only one of them is rendered at a time.
