---
title: Tailwind CSS Navbar
description: Beautiful, modern navbar component for Tailwind CSS. Use it to add site navigation, like a sticky header, a mega menu or a responsive menu. Easily customizable.
---

Use the navbar component to put your brand, links and actions across the top of a page, like a site header with a mega menu or the header of a dashboard. For a vertical menu, use a [sidebar](/components/sidebar).

## Usage

Add the `navbar` class to a `<header>` element and fill it with what your site needs: your logo in a [brand](/components/brand), the links in a `navbar-nav`, each with `navbar-link` and `active` on the current page, and the buttons in a `navbar-actions` group. Wrap any logo in a brand, whether an image or your own svg, so the drawer can show it at the top.

For a dropdown or a mega menu, put a `navbar-content` panel right after a `navbar-link` button and point it at the button with `data-sp-toggle`. Fill it with `navbar-link` rows and add a `navbar-link-description` inside a row for a line under its title. For a mega menu, lay the rows out in columns with a `grid` inside the panel, and start a column with a `navbar-label` to name it. Add a `navbar-feature` column for an announcement or a featured story, with a `navbar-feature-title` and a `navbar-feature-description` inside.

To fold the menu away on small screens, wrap the `navbar-nav` and the actions in a `navbar-collapse`, and point that at an empty `navbar-toggle` button with an `aria-label`. Below the `md` breakpoint, or your own [`--breakpoint-navbar`](#css-variables), the wrapper becomes a drawer in the style of the [sidebar](/components/sidebar), with each panel as a sub-menu that shows only the link titles. Leave the `navbar-collapse` out to keep the menu in the bar on every screen size, scrolling sideways when it runs out of room.

The bar has no border of its own. Add `border-b` for one. On a sticky bar, including a sticky overlay, it fades in once the page scrolls.

| Class                        | Description                                                                                   |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| `navbar`                     | Add to the `<header>` element                                                                 |
| `navbar-sticky`              | Add to `navbar` to keep it in view. It gets `scrolled` once content passes under it           |
| `navbar-overlay`             | Add to `navbar` to lay it see-through over a hero, with `navbar-sticky` to keep it in view    |
| `navbar-start`               | Add to `navbar` to place the menu after the brand, the default, for example at a breakpoint   |
| `navbar-center`              | Add to `navbar` to center the menu on the bar, with any extra buttons inside `navbar-actions` |
| `navbar-end`                 | Add to `navbar` to move the menu next to the buttons at the end                               |
| `navbar-sm`                  | Add to `navbar` for a shorter bar with smaller links                                          |
| `navbar-nav`                 | Add to the `<nav>` element holding the links                                                  |
| `navbar-nav-line`            | Add to `navbar-nav` for muted links and a line under the current one                          |
| `navbar-link`                | Add to each link or button, with `active` on the current page                                 |
| `navbar-link-description`    | Add to a `<span>` inside a panel link for a line under its title                              |
| `navbar-content`             | Add to the panel, which carries `data-sp-toggle`                                              |
| `navbar-label`               | Add to the heading of a column in a panel                                                     |
| `navbar-feature`             | Add to a column in a panel for featured content, which the drawer leaves out                  |
| `navbar-feature-title`       | Add to the title in a `navbar-feature`                                                        |
| `navbar-feature-description` | Add to a line of supporting text in a `navbar-feature`                                        |
| `navbar-collapse`            | Add to a wrapper around the links and the actions that folds on small screens                 |
| `navbar-toggle`              | Add to the empty button that opens the drawer                                                 |
| `navbar-actions`             | Add to the group of buttons at the end of the bar                                             |

```html
<header class="navbar">
  <a href="/" class="brand">...</a>
  <button id="menu-toggle" class="btn btn-ghost btn-icon navbar-toggle ms-auto" aria-label="Toggle menu"></button>
  <div class="navbar-collapse" data-sp-toggle="#menu-toggle">
    <nav class="navbar-nav">
      <a href="#" class="navbar-link active">Home</a>
      <button id="products" class="navbar-link">Products ...</button>
      <div class="navbar-content" data-sp-toggle="#products">
        <div class="grid w-lg grid-cols-2 gap-2">
          <div>
            <div class="navbar-label">Platform</div>
            <a href="#" class="navbar-link">
              Analytics
              <span class="navbar-link-description">Dashboards and reports.</span>
            </a>
          </div>
          <div>...</div>
        </div>
      </div>
      <a href="#" class="navbar-link">Pricing</a>
    </nav>
    <div class="navbar-actions">...</div>
  </div>
</header>
```

## CSS variables

| Variable           | Default                             | Description                 |
| ------------------ | ----------------------------------- | --------------------------- |
| `--navbar-height`  | `3.5rem`, `2.5rem` with `navbar-sm` | The height of the bar       |
| `--navbar-padding` | `1rem`, `1.5rem` from `md`          | The side padding of the bar |

```html
<header class="navbar [--navbar-height:3rem]">...</header>
```

The menu folds below the `navbar` breakpoint, `md` by default. Move it with `--breakpoint-navbar` in your theme, and use the matching `navbar:` and `max-navbar:` variants in your markup.

```css
@theme {
  --breakpoint-navbar: 64rem;
}
```

## Options

Set each option with its own `data-sp-*` attribute on the `navbar-content` panel. The `navbar-collapse` takes `data-sp-toggle` the same way.

| Attribute              | Values                | Default                                                         |
| ---------------------- | --------------------- | --------------------------------------------------------------- |
| `data-sp-toggle`       | CSS selector          | None                                                            |
| `data-sp-placement`    | Floating UI placement | `bottom-start`                                                  |
| `data-sp-offset`       | Number                | `8`                                                             |
| `data-sp-align-offset` | Number                | `0`                                                             |
| `data-sp-mode`         | `hover` \| `click`    | `hover`                                                         |
| `data-sp-item`         | CSS selector          | `.navbar-link`, and the links and buttons in a `navbar-feature` |

```html
<div class="navbar-content" data-sp-toggle="#products" data-sp-placement="bottom"></div>
```

In `hover` mode a panel opens while the pointer rests on its button and closes once the pointer leaves. A click on the button pins it open until you press elsewhere. Touch and the keyboard open it like `click` mode.

## JavaScript

### Events

Lifecycle events fire on a panel and on the drawer. The `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before opening (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before closing (cancelable) |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

```js
const menu = document.querySelector(".navbar-collapse");

menu.addEventListener("sp-shown", () => {
  // The drawer is open
});
```

### Methods

Get a panel with `sp.navbarContent(el)` and the drawer with `sp.navbarCollapse(el)`, then call their methods:

| Method     | Description                   |
| ---------- | ----------------------------- |
| `show()`   | Open the panel or the drawer  |
| `hide()`   | Close the panel or the drawer |
| `toggle()` | Open if closed, else close    |

```js
const products = sp.navbarContent(document.querySelector("#products-panel"));

products.show();
```
