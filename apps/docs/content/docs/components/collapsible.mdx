---
title: Collapsible
description: A Tailwind CSS collapsible component for expanding and collapsing content in place, an accessible disclosure with an animated height transition.
---

The collapsible expands and collapses a block of content in place. Use it for show-more text, expandable table rows, and nested navigation trees; for a group of sections where opening one closes the others, reach for the [accordion](/components/accordion).

## Usage

Add the `collapsible` class to an element and give it an `id`. Give your trigger an `id` too, then point the panel at it with `data-sp-toggle`. Wrap the panel's children in `collapsible-content`.

| Class                 | Description                                                       |
| --------------------- | ----------------------------------------------------------------- |
| `collapsible`         | Add to the panel that expands and collapses; carries `data-sp-toggle` |
| `collapsible-content` | Add to the wrapper around the panel's children                    |

```html
<!-- This is the trigger -->
<button id="my-trigger" class="btn">Toggle</button>

<!-- This is the panel -->
<div class="collapsible" data-sp-toggle="#my-trigger">
  <div class="collapsible-content">Hidden content</div>
</div>
```

## Options

### Collapsible

Set each option with its own `data-sp-*` attribute on the `collapsible` element.

| Attribute        | Values       | Default |
| ---------------- | ------------ | ------- |
| `data-sp-toggle` | CSS selector | —       |

```html
<div class="collapsible" data-sp-toggle="#my-trigger">
```

## JavaScript

### Events

Lifecycle events fire on the panel; `before*` events are cancelable.

| Event               | When                           |
| ------------------- | ------------------------------ |
| `sp-beforeexpand`   | Before expanding (cancelable)  |
| `sp-expand`         | Expanding                      |
| `sp-expanded`       | Expanded and settled           |
| `sp-beforecollapse` | Before collapsing (cancelable) |
| `sp-collapse`       | Collapsing                     |
| `sp-collapsed`      | Collapsed and settled          |

```js
// Veto collapsing, e.g. while a form inside has unsaved changes.
panel.addEventListener("sp-beforecollapse", (e) => {
  if (unsavedChanges) e.preventDefault();
});
```

### Methods

Get the instance with `sp.collapsible(el)`, then call its methods:

| Method       | Description                        |
| ------------ | ---------------------------------- |
| `expand()`   | Expand the panel                   |
| `collapse()` | Collapse the panel                 |
| `toggle()`   | Expand if collapsed, else collapse |

```js
const collapsible = sp.collapsible(document.querySelector("#my-panel"));

collapsible.expand();
```

## Accessibility

The collapsible adheres to the [Disclosure WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) and sets the appropriate roles and properties automatically.
