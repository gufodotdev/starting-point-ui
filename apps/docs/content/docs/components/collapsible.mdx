title: Collapsible
description: An accessible collapsible component for Tailwind CSS, expanding and collapsing content in place.
---

A panel that expands and collapses in place, with an animated height transition.

## Basic Usage

Add the `collapsible-panel` class to an element and a `data-sp-collapsible` attribute with a `toggle` option pointing at the trigger's `id`. Wrap the panel's children in `collapsible-content`. The trigger's `aria-expanded` and `aria-controls` are wired automatically, so styles like the chevron swap below can key off `aria-expanded`.

```html preview
<div class="flex w-full max-w-sm flex-col gap-2">
  <div class="flex items-center justify-between gap-4">
    <h4 class="text-sm font-semibold">@gufodev starred 3 repositories</h4>
    <button id="collapsible-1-trigger" class="btn btn-ghost btn-icon btn-sm">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="in-aria-expanded:hidden"><path d="m7 15 5 5 5-5"/><path d="m7 9 5-5 5 5"/></svg>
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="hidden in-aria-expanded:block"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg>
      <span class="sr-only">Toggle</span>
    </button>
  </div>
  <div class="rounded-md border px-4 py-2 font-mono text-sm">
    tailwindlabs/tailwindcss
  </div>
  <div class="collapsible-panel" data-sp-collapsible="toggle: #collapsible-1-trigger">
    <div class="collapsible-content">
      <div class="rounded-md border px-4 py-2 font-mono text-sm">
        twbs/bootstrap
      </div>
      <div class="rounded-md border px-4 py-2 font-mono text-sm">
        shadcn-ui/ui
      </div>
    </div>
  </div>
</div>
```

## Initially open

Add the `shown` class to the panel so it renders open on first paint, before JavaScript loads. Set `aria-expanded="true"` on the trigger so its state matches.

```html preview
<div class="flex w-full max-w-sm flex-col gap-2">
  <div class="flex items-center justify-between gap-4">
    <h4 class="text-sm font-semibold">Starred repositories</h4>
    <button id="collapsible-open-trigger" class="btn btn-ghost btn-icon btn-sm" aria-expanded="true">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="in-aria-expanded:hidden"><path d="m7 15 5 5 5-5"/><path d="m7 9 5-5 5 5"/></svg>
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="hidden in-aria-expanded:block"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg>
      <span class="sr-only">Toggle</span>
    </button>
  </div>
  <div class="collapsible-panel shown" data-sp-collapsible="toggle: #collapsible-open-trigger">
    <div class="collapsible-content">
      <div class="rounded-md border px-4 py-2 font-mono text-sm">
        tailwindlabs/tailwindcss
      </div>
      <div class="rounded-md border px-4 py-2 font-mono text-sm">
        twbs/bootstrap
      </div>
    </div>
  </div>
</div>
```

## Options

Set options in the `data-sp-collapsible` value, separated by semicolons.

| Option   | Type   | Default | Description                                   |
| -------- | ------ | ------- | --------------------------------------------- |
| `toggle` | String | —       | Selector for the element that toggles the panel |

## Events

Lifecycle events fire on the panel element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before expanding (cancelable) |
| `sp-show`       | Expanding                   |
| `sp-shown`      | Expanded and settled        |
| `sp-beforehide` | Before collapsing (cancelable) |
| `sp-hide`       | Collapsing                  |
| `sp-hidden`     | Collapsed                   |

## Methods

Get the instance with `sp.collapsible(el)`, then call its methods:

| Method     | Description                    |
| ---------- | ------------------------------ |
| `show()`   | Expand the panel               |
| `hide()`   | Collapse the panel             |
| `toggle()` | Expand if collapsed, else collapse |

```js
const collapsible = sp.collapsible(document.querySelector("#my-panel"));

collapsible.show();
```

## Accessibility

The collapsible adheres to the [Disclosure WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) and sets the appropriate properties automatically. Enter and Space on the trigger toggle the panel.
