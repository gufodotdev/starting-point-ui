title: Toast
description: An accessible toast component for Tailwind CSS, showing temporary notifications and feedback messages.
---

Temporary notifications created from JavaScript, stacked per position and auto-dismissed after a configurable duration.

## Basic Usage

Call `sp.toast()` with a title. The toast, its stacking container, and all accessibility wiring are created for you. Multiple toasts collapse into a stack with the newest in front; hovering the stack expands it to the full list and pauses every auto-dismiss timer.

```html preview
<button class="btn" onclick="sp.toast('Event has been created')">
  Show Toast
</button>
```

## Types

Set the `type` option, or use the shorthand methods `sp.toast.success()`, `sp.toast.error()`, `sp.toast.warning()`, `sp.toast.info()`, and `sp.toast.loading()`.

```html preview
<div class="flex flex-wrap gap-2">
  <button class="btn" onclick="sp.toast('A default toast notification')">
    Default
  </button>
  <button class="btn" onclick="sp.toast.success('Changes saved successfully')">
    Success
  </button>
  <button class="btn" onclick="sp.toast.error('Failed to save changes')">
    Error
  </button>
  <button class="btn" onclick="sp.toast.warning('This action cannot be undone')">
    Warning
  </button>
  <button class="btn" onclick="sp.toast.info('A new version is available')">
    Info
  </button>
</div>
```

## With description

Add a secondary line of text with the `description` option.

```html preview
<button
  class="btn"
  onclick="sp.toast.success('Profile updated', { description: 'Your changes have been saved and are now live.' })"
>
  With Description
</button>
```

## With action

Add a clickable action button to the toast.

```html preview
<button
  class="btn"
  onclick="sp.toast('File deleted', { description: 'report-2024.pdf was moved to trash.', action: { label: 'Undo', onClick: () => sp.toast.success('File restored') } })"
>
  With Action
</button>
```

## Loading and update

Use `sp.toast.loading()` to show a spinner. Loading toasts don't auto-dismiss and aren't dismissible by default. Use `update()` on the returned toast instance to swap it to a different state.

```html preview
<button
  class="btn"
  onclick="(function(){ var t = sp.toast.loading('Loading data...'); setTimeout(function(){ t.update({ title: 'Data loaded successfully', type: 'success' }) }, 2000) })()"
>
  Loading → Success
</button>
```

```js
const t = sp.toast.loading("Creating post...");

const res = await fetch("/api/posts", { method: "POST", body });

if (res.ok) {
  t.update({ title: "Post created", type: "success" });
} else {
  t.update({ title: "Failed to create post", type: "error" });
}
```

## Duration

Control how long the toast stays visible (in milliseconds). Default is 4000ms. Set `0` for a persistent toast that must be dismissed manually.

```html preview
<div class="flex flex-wrap gap-2">
  <button class="btn" onclick="sp.toast('Gone in 2 seconds', { duration: 2000 })">
    Short (2s)
  </button>
  <button class="btn" onclick="sp.toast('Staying for 10 seconds', { duration: 10000 })">
    Long (10s)
  </button>
  <button class="btn" onclick="sp.toast('I won\'t go away on my own', { duration: 0 })">
    Persistent
  </button>
</div>
```

## Position

Place the toast container in any corner or centered at the top or bottom. Default is `bottom-right`.

```html preview
<div class="flex flex-wrap gap-2">
  <button class="btn" onclick="sp.toast('Top left', { position: 'top-left' })">
    Top Left
  </button>
  <button class="btn" onclick="sp.toast('Top center', { position: 'top-center' })">
    Top Center
  </button>
  <button class="btn" onclick="sp.toast('Top right', { position: 'top-right' })">
    Top Right
  </button>
  <button class="btn" onclick="sp.toast('Bottom left', { position: 'bottom-left' })">
    Bottom Left
  </button>
  <button class="btn" onclick="sp.toast('Bottom center', { position: 'bottom-center' })">
    Bottom Center
  </button>
  <button class="btn" onclick="sp.toast('Bottom right', { position: 'bottom-right' })">
    Bottom Right
  </button>
</div>
```

## Non-dismissible

Set `dismissible: false` to hide the close button. The toast disappears only when its duration expires.

```html preview
<button
  class="btn"
  onclick="sp.toast.info('Processing your request...', { dismissible: false, duration: 3000 })"
>
  Non-dismissible
</button>
```

## Declarative toasts

Add a `data-sp-toast` attribute to any element to fire it as a toast and remove the element, with a plain string or a JSON config. New elements are picked up as they enter the DOM, so server-rendered redirects can queue flash messages with no JavaScript.

```html
<div data-sp-toast="Changes saved"></div>

<div data-sp-toast='{"title":"Post created","type":"success","description":"Your post is now live."}'></div>
```

For example, in Laravel Blade:

```blade
@if (session('toast'))
    <div data-sp-toast='@json(session("toast"))'></div>
@endif
```

```php
return redirect()->back()->with('toast', [
    'title' => 'Post created',
    'type' => 'success',
]);
```

Toasts queued this way survive being rendered by React, Livewire, HTMX, or anything else that inserts nodes after page load. On Back/Forward navigation, cached flash markup does not re-fire.

## Options

Pass options as the second argument to `sp.toast()`.

| Option        | Type     | Default        | Description                                                       |
| ------------- | -------- | -------------- | ----------------------------------------------------------------- |
| `type`        | String   | `default`      | `success`, `error`, `warning`, `info`, or `loading`               |
| `description` | String   | —              | Secondary text under the title                                    |
| `duration`    | Number   | `4000`         | Milliseconds before auto-dismiss; `0` keeps the toast until dismissed |
| `action`      | Object   | —              | `{ label, onClick }` rendered as a button; clicking also dismisses |
| `position`    | String   | `bottom-right` | `top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right` |
| `dismissible` | Boolean  | `true`         | Show the close button                                             |

## Events

Lifecycle events fire on each toast element and bubble to `document`.

| Event       | When               |
| ----------- | ------------------ |
| `sp-show`   | Entering           |
| `sp-shown`  | Shown and settled  |
| `sp-hide`   | Leaving            |
| `sp-hidden` | Removed            |

## Methods

`sp.toast()` returns a toast instance; the module also exposes global helpers.

| Method                      | Description                                  |
| --------------------------- | -------------------------------------------- |
| `sp.toast(title, options)`  | Show a toast, returns `{ id, update, dismiss }` |
| `sp.toast.success(title, options)` | Shorthand for each type (`success`, `error`, `warning`, `info`, `loading`) |
| `instance.update(options)`  | Swap title, type, description, and duration in place |
| `instance.dismiss()`        | Dismiss this toast                           |
| `sp.toast.dismiss(id)`      | Dismiss a toast by id                        |
| `sp.toast.dismissAll()`     | Dismiss every toast                          |

## Accessibility

Toasts render as `role="status"` items inside an `aria-live="polite"` region, so screen readers announce them without interrupting the user. Hovering or focusing a toast pauses its auto-dismiss timer.
