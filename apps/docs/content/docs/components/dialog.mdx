A modal dialog for confirmations, forms, and alerts.

## Basic Usage

Add the `dialog` class to a `<dialog>` element and a `data-sp-dialog` attribute with a `toggle` option pointing at the trigger's `id`. Add `data-sp-dismiss` to any button to close it, or close with a click on the backdrop or the Escape key.

```html preview
<button id="dialog-1-trigger" class="btn">Open Dialog</button>

<dialog class="dialog" data-sp-dialog="toggle: #dialog-1-trigger">
  <button
    class="btn btn-ghost btn-icon-xs absolute top-3 right-3"
    aria-label="Close"
    data-sp-dismiss
  >
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="size-4"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg>
  </button>
  <div class="dialog-content grid gap-6">
    <div>
      <h2 class="dialog-title">Confirm changes</h2>
      <p class="dialog-description">
        Dismiss this dialog by clicking the backdrop, pressing Escape, or using
        the close button.
      </p>
    </div>
    <div class="grid grid-cols-2 gap-2">
      <button class="btn" data-sp-dismiss>Cancel</button>
      <button class="btn btn-primary" data-sp-dismiss>Confirm</button>
    </div>
  </div>
</dialog>
```

## Static Backdrop

Add `static: true` so the backdrop won't close the dialog and the user has to pick an action. Escape still closes it, so keyboard users are never stuck.

```html preview
<button id="static-trigger" class="btn">Delete account</button>

<dialog class="dialog" data-sp-dialog="toggle: #static-trigger; static: true">
  <div class="dialog-content grid gap-6">
    <div>
      <h2 class="dialog-title">Delete account</h2>
      <p class="dialog-description">
        Clicking outside won't dismiss this. Choose an action to continue.
      </p>
    </div>
    <div class="grid grid-cols-2 gap-2">
      <button class="btn" data-sp-dismiss>Cancel</button>
      <button class="btn btn-destructive" data-sp-dismiss>Delete</button>
    </div>
  </div>
</dialog>
```

## Options

Set options in the `data-sp-dialog` value, separated by semicolons.

| Option   | Type    | Default | Description                                            |
| -------- | ------- | ------- | ------------------------------------------------------ |
| `toggle` | String  | —       | Selector for the element that opens the dialog         |
| `static` | Boolean | `false` | Backdrop click won't close the dialog (Escape still does) |

## Events

Lifecycle events fire on the dialog element; `before*` events are cancelable.

| Event              | When                                       |
| ------------------ | ------------------------------------------ |
| `sp:beforeshow`    | Before showing (cancelable)                |
| `sp:show`          | Opening                                     |
| `sp:shown`         | Open and settled                           |
| `sp:beforehide`    | Before hiding (cancelable)                 |
| `sp:hide`          | Closing                                     |
| `sp:hidden`        | Closed                                      |
| `sp:hideprevented` | A static dialog refused a backdrop dismiss |

```js
el.addEventListener("sp:beforeshow", (e) => {
  if (!ready) e.preventDefault(); // veto the open
});
```

## Methods

Get the instance with `sp.dialog(el)`, then call its methods:

| Method     | Description                 |
| ---------- | -------------------------- |
| `show()`   | Open the dialog            |
| `hide()`   | Close the dialog           |
| `toggle()` | Open if closed, else close |

```js
const dialog = sp.dialog(document.querySelector("#my-dialog"));

dialog.show();
```

## Accessibility

The dialog adheres to the [Dialog (Modal) WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) and sets the appropriate roles and properties automatically.
