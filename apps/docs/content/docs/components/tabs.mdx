A set of tabs switching between content panels in place.

## Basic Usage

Add `data-sp-tabs` to a wrapper holding a `tab-list` of `tab` buttons and one `tab-panel` per tab. The first tab pairs with the first panel, the second with the second, and so on. Mark the initially selected tab and its panel with `active`, so the markup renders correctly before JavaScript loads.

Clicking a tab or moving through the list with the arrow keys switches the panels. All ids, roles, and ARIA attributes are generated, so the only markup the component asks for is `active` on the starting pair.

```html preview
<div data-sp-tabs class="w-96">
  <div class="tab-list">
    <button class="tab active">Account</button>
    <button class="tab">Password</button>
    <button class="tab">Settings</button>
  </div>
  <div class="tab-panel mt-2 active">
    <div class="card">
      <div class="card-content">
        <h3 class="font-medium mb-2">Account</h3>
        <p class="text-sm text-muted-foreground">
          Manage your account settings and preferences.
        </p>
      </div>
    </div>
  </div>
  <div class="tab-panel mt-2">
    <div class="card">
      <div class="card-content">
        <h3 class="font-medium mb-2">Password</h3>
        <p class="text-sm text-muted-foreground">
          Change your password and security options.
        </p>
      </div>
    </div>
  </div>
  <div class="tab-panel mt-2">
    <div class="card">
      <div class="card-content">
        <h3 class="font-medium mb-2">Settings</h3>
        <p class="text-sm text-muted-foreground">
          Configure your application preferences.
        </p>
      </div>
    </div>
  </div>
</div>
```

## Disabled tabs

Add `disabled` to a tab to prevent selection. Arrow navigation skips it.

```html preview
<div data-sp-tabs class="w-96">
  <div class="tab-list">
    <button class="tab active">Free</button>
    <button class="tab" disabled>Pro</button>
    <button class="tab">Enterprise</button>
  </div>
  <div class="tab-panel mt-2 active">
    <p class="text-sm text-muted-foreground">The free plan.</p>
  </div>
  <div class="tab-panel mt-2">
    <p class="text-sm text-muted-foreground">The pro plan.</p>
  </div>
  <div class="tab-panel mt-2">
    <p class="text-sm text-muted-foreground">The enterprise plan.</p>
  </div>
</div>
```

## Vertical

Set `orientation: vertical` so Up and Down move between tabs instead of Left and Right, and lay the list out with utilities.

```html preview
<div data-sp-tabs="orientation: vertical" class="flex w-96 gap-4">
  <div class="tab-list h-auto flex-col items-stretch">
    <button class="tab active">General</button>
    <button class="tab">Members</button>
    <button class="tab">Billing</button>
  </div>
  <div class="tab-panel active">
    <p class="text-sm text-muted-foreground">General settings.</p>
  </div>
  <div class="tab-panel">
    <p class="text-sm text-muted-foreground">Manage members.</p>
  </div>
  <div class="tab-panel">
    <p class="text-sm text-muted-foreground">Billing details.</p>
  </div>
</div>
```

## Options

Set options in the `data-sp-tabs` value, separated by semicolons.

| Option        | Type   | Default      | Description                                |
| ------------- | ------ | ------------ | ------------------------------------------ |
| `orientation` | String | `horizontal` | `vertical` switches arrow keys to Up/Down  |

## Events

Events fire on the `data-sp-tabs` element; `sp-beforechange` is cancelable and both carry the tab in `detail.tab`.

| Event             | When                              |
| ----------------- | --------------------------------- |
| `sp-beforechange` | Before switching (cancelable)     |
| `sp-change`       | A tab and its panel were selected |

```js
el.addEventListener("sp-beforechange", (e) => {
  if (unsavedChanges) e.preventDefault(); // veto the switch
});
```

## Methods

Get the instance with `sp.tabs(el)`, then call its methods:

| Method        | Description            |
| ------------- | ---------------------- |
| `select(tab)` | Select a `tab` element |

```js
const tabs = sp.tabs(document.querySelector("#my-tabs"));

tabs.select(document.querySelector("#my-tabs .tab:last-child"));
```

## Accessibility

The tabs adhere to the [Tabs WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) and set the appropriate roles and properties automatically, with automatic activation: moving focus selects. If a page holds several tab sets, an `aria-label` on each `tab-list` helps screen reader users tell them apart.

| Key                        | Action                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------- |
| `ArrowRight` / `ArrowLeft` | Select the next or previous tab, wrapping (vertical lists use `ArrowDown` / `ArrowUp`)  |
| `Home` / `End`             | Select the first or last tab                                                            |
| `Tab`                      | Moves from the active tab into its panel                                                |
