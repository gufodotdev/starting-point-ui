title: Input Group
description: An input group component for Tailwind CSS with beautiful shadcn/ui styling. Use it to put icons, text, and buttons inside one bordered field.
---

The input group wraps an [input](/components/input) or [textarea](/components/textarea) in a single bordered field and lets icons, text, buttons, and whole toolbars sit inside it. For attaching full-size buttons next to a field, reach for the [button group](/components/button-group) instead.

```html preview preset=form
<div class="input-group">
  <input class="input" placeholder="Search..." />
  <span class="input-group-addon"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg></span>
  <span class="input-group-addon input-group-addon-end">12 results</span>
</div>
```

## Usage

Add the `input-group` class to the wrapper and put a regular [input](/components/input) or [textarea](/components/textarea) inside; the wrapper strips its border and takes over as the field chrome. Extras go in `input-group-addon` elements, and regular [buttons](/components/button) inside an addon shrink to fit the field automatically. The wrapper draws the border, focus ring, and invalid state for the whole field.

| Class                          | Description                                                       |
| ------------------------------ | ----------------------------------------------------------------- |
| `input-group`                  | Add to the wrapper; carries the border, focus ring, and invalid state |
| `input-group-addon`            | Add to an element holding icons, text, or buttons (leading by default) |
| `input-group-addon-end`        | Add to `input-group-addon` to trail the input                     |
| `input-group-addon-block-start`| Add to `input-group-addon` for a full-width header row            |
| `input-group-addon-block-end`  | Add to `input-group-addon` for a full-width footer row            |
| `input-group-text`             | Add to a `<span>` for muted static text inside an addon           |

```html
<div class="input-group">
  <input class="input" placeholder="Search..." />
  <span class="input-group-addon"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg></span>
</div>
```

## Examples

### Align start

The default addon leads the input.

```html preview preset=form
<div class="field">
  <label class="label" for="ig-start-input">Input</label>
  <div class="input-group">
    <input class="input" id="ig-start-input" placeholder="Search..." />
    <span class="input-group-addon"><svg class="text-muted-foreground" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg></span>
  </div>
  <p class="field-description">Icon positioned at the start.</p>
</div>
```
