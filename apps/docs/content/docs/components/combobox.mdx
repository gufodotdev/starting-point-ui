title: Combobox
description: An accessible combobox for Tailwind CSS that combines a trigger button with a searchable, keyboard-navigable option list.

A trigger button with a searchable option list, supporting single and multi select.

## Basic Usage

Add the `combobox` class to a panel with a `data-sp-combobox` attribute whose `toggle` option points at the trigger's `id`. The trigger holds a `combobox-value` span that displays the selection (or its `data-sp-placeholder` while empty). Each `combobox-item` wraps a visually hidden `<input type="radio">` (single select) or `<input type="checkbox">` (multi select) with a `name` and `value`.

Opening the combobox focuses the search input. Typing filters the items, arrow keys move the highlight through the visible ones, and Enter or a click selects. Single select closes on selection, and selecting the chosen option again clears it, so optional fields can return to empty. The search resets whenever the menu closes.

```html preview
<button id="combobox-1-trigger" class="combobox-trigger w-56">
  <span class="combobox-value" data-sp-placeholder="Select a framework..."></span>
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="text-muted-foreground"><path d="m7 15 5 5 5-5"/><path d="m7 9 5-5 5 5"/></svg>
</button>

<div class="combobox" data-sp-combobox="toggle: #combobox-1-trigger">

    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg>
    <input class="combobox-input" type="text" placeholder="Search framework..." />
  </div>
  <div class="combobox-list">
    <div class="combobox-item">
      <input type="radio" class="sr-only" tabindex="-1" name="framework" value="next" />
      Next.js
    </div>
    <div class="combobox-item">
      <input type="radio" class="sr-only" tabindex="-1" name="framework" value="sveltekit" />
      SvelteKit
    </div>
    <div class="combobox-item">
      <input type="radio" class="sr-only" tabindex="-1" name="framework" value="nuxt" />
      Nuxt.js
    </div>
    <div class="combobox-item">
      <input type="radio" class="sr-only" tabindex="-1" name="framework" value="astro" />
```

## Pre-selected value

Add `checked` to the input and `aria-selected="true"` to the item, then render one `<span>` child per selection inside `combobox-value`. The CSS handles single and multi states automatically.

```html preview

  <span class="combobox-value" data-sp-placeholder="Select a framework...">
    <span>SvelteKit</span>
  </span>
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="text-muted-foreground"><path d="m7 15 5 5 5-5"/><path d="m7 9 5-5 5 5"/></svg>

<div class="combobox" data-sp-combobox="toggle: #combobox-pre-trigger">

    <div class="combobox-item">
      <input type="radio" class="sr-only" tabindex="-1" name="pre-framework" value="next" />
      Next.js

```

## Static trigger

For triggers that should never show selection state, like a column-visibility toggle, leave out the `combobox-value` span and write the label as plain content. The selection only ever renders into a `combobox-value` span, so without one the trigger keeps its label.

```html preview

      <input type="checkbox" class="sr-only" tabindex="-1" name="cols" value="role" />
```

```html preview
</div>
```

## Options

Set options in the `data-sp-combobox` value, separated by semicolons.

| Option       | Type    | Default                       | Description                                               |
| ------------ | ------- | ----------------------------- | --------------------------------------------------------- |
| `toggle`     | String  | —                             | Selector for the element that opens the combobox          |
| `placement`  | String  | `bottom-start`                | Position relative to the trigger (Floating UI placement)  |
| `offset`     | Number  | `4`                           | Gap in pixels between the trigger and the panel           |
| `matchWidth` | Boolean | `true`                        | Match the panel width to the trigger width                |
| `item`       | String  | `.combobox-item:not([hidden])` | Selector for the entries arrow navigation moves between  |

## Events

Lifecycle events fire on the combobox element; `before*` events are cancelable. Selecting an item also dispatches a native `change` event from its input, bubbling through the panel and any enclosing form.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before showing (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before hiding (cancelable)  |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

```js
el.addEventListener("change", (e) => {
  console.log(e.target.name, e.target.value, e.target.checked);
});
```

## Methods

Get the instance with `sp.combobox(el)`, then call its methods:

| Method          | Description                                     |
| --------------- | ----------------------------------------------- |
| `show()`        | Open the panel                                  |
| `hide()`        | Close the panel                                 |
| `toggle()`      | Open if closed, else close                      |
| `select(item)`  | Select a `combobox-item` element programmatically |
| `filter(query)` | Filter the items, as if typed into the search   |

```js
const combobox = sp.combobox(document.querySelector("#my-combobox"));

combobox.filter("next");
combobox.select(document.querySelector("#my-combobox .combobox-item"));
```

## Accessibility

The combobox adheres to the [Combobox WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) and sets the appropriate roles and properties automatically. Focus stays in the search input while arrow keys move a highlight, so typing and navigating mix freely.

| Key                              | Action                                                       |
| -------------------------------- | ------------------------------------------------------------ |
| `Enter` / `Space` / `ArrowDown`  | Opens the panel from the trigger and focuses the search input |
| `Escape`                         | Closes the panel and returns focus to the trigger            |
| `ArrowDown` / `ArrowUp`          | Move the highlight through visible items, wrapping            |
| `Enter`                          | Selects the highlighted item                                  |
| `Tab`                            | Leaves the combobox and closes it                             |
