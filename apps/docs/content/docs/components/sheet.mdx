A modal panel that slides in from a screen edge, for navigation, filters, and details.

## Basic Usage

Add the `sheet` class to a `<dialog>` element and a `data-sp-sheet` attribute with a `toggle` option pointing at the trigger's `id`. Add `data-sp-dismiss` to any button to close it, or close with a click on the backdrop or the Escape key.

```html preview
<button id="sheet-1-trigger" class="btn">Open Sheet</button>

<dialog class="sheet" data-sp-sheet="toggle: #sheet-1-trigger">
  <button
    class="btn btn-ghost btn-icon-sm absolute top-2 right-2"
    aria-label="Close"
    data-sp-dismiss
  >
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="size-5"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg>
  </button>
  <div class="sheet-content">
    <h2 class="sheet-title">Sheet Title</h2>
    <p class="sheet-description">
      A modal sheet. Close it with the button, a backdrop click, or Escape.
    </p>
  </div>
</dialog>
```

## Directions

Set the edge the sheet slides from with `sheet-left`, `sheet-right`, `sheet-top`, or `sheet-bottom`. Without one, it defaults to `sheet-left`.

```html preview
<button id="dir-left" class="btn">Left</button>

<dialog class="sheet sheet-left" data-sp-sheet="toggle: #dir-left">
  <div class="sheet-content">
    <h2 class="sheet-title">Left</h2>
    <p class="sheet-description">Great for navigation menus.</p>
    <button class="btn mt-4" data-sp-dismiss>Close</button>
  </div>
</dialog>

<button id="dir-right" class="btn">Right</button>

<dialog class="sheet sheet-right" data-sp-sheet="toggle: #dir-right">
  <div class="sheet-content">
    <h2 class="sheet-title">Right</h2>
    <p class="sheet-description">Great for details or settings.</p>
    <button class="btn mt-4" data-sp-dismiss>Close</button>
  </div>
</dialog>

<button id="dir-top" class="btn">Top</button>

<dialog class="sheet sheet-top" data-sp-sheet="toggle: #dir-top">
  <div class="sheet-content">
    <h2 class="sheet-title">Top</h2>
    <p class="sheet-description">Great for notifications.</p>
    <button class="btn mt-4" data-sp-dismiss>Close</button>
  </div>

```

## Static Backdrop

Add `static: true` so the backdrop won't close the sheet and the user has to pick an action. Escape still closes it, so keyboard users are never stuck.

```html preview
<button id="sheet-static-trigger" class="btn">Delete account</button>

<dialog
  class="sheet sheet-right"
  data-sp-sheet="toggle: #sheet-static-trigger; static: true"
>
  <div class="sheet-content grid gap-6">
    <div>
      <h2 class="sheet-title">Are you sure?</h2>
      <p class="sheet-description">
        Clicking outside won't dismiss this. Choose an action to continue.
      </p>
    </div>
    <div class="grid grid-cols-2 gap-2">
      <button class="btn" data-sp-dismiss>Cancel</button>
      <button class="btn btn-destructive" data-sp-dismiss>Delete</button>
    </div>
  </div>
</dialog>
```

## Options

Set options in the `data-sp-sheet` value, separated by semicolons.

| Option   | Type    | Default | Description                                           |
| -------- | ------- | ------- | ----------------------------------------------------- |
| `toggle` | String  | —       | Selector for the element that opens the sheet         |
| `static` | Boolean | `false` | Backdrop click won't close the sheet (Escape still does) |

| Attribute         | Description                                  |
| ----------------- | -------------------------------------------- |
| `data-sp-dismiss` | Add to a button inside the sheet to close it |

## Events

Lifecycle events fire on the sheet element; `before*` events are cancelable.

| Event              | When                                       |
| ------------------ | ------------------------------------------ |
| `sp-beforeshow`    | Before showing (cancelable)                |
| `sp-show`          | Opening                                     |
| `sp-shown`         | Open and settled                           |
| `sp-beforehide`    | Before hiding (cancelable)                 |
| `sp-hide`          | Closing                                     |
| `sp-hidden`        | Closed                                      |
| `sp-hideprevented` | A static sheet refused a backdrop dismiss  |

```js
el.addEventListener("sp-beforeshow", (e) => {
  if (!ready) e.preventDefault(); // veto the open
});
```

## Methods

Get the instance with `sp.sheet(el)`, then call its methods:

| Method     | Description                 |
| ---------- | -------------------------- |
| `show()`   | Open the sheet             |
| `hide()`   | Close the sheet            |
| `toggle()` | Open if closed, else close |

```js
const sheet = sp.sheet(document.querySelector("#my-sheet"));

sheet.show();
```

## Accessibility

The sheet adheres to the [Dialog (Modal) WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) and sets the appropriate roles and properties automatically.
