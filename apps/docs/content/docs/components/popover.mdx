A non-modal floating panel anchored to a trigger, for rich content, forms, and menus.

## Basic Usage

Add the `popover` class to an element and a `data-sp-popover` attribute with a `toggle` option pointing at the trigger's `id`. It opens on click and closes on Escape, an outside click, or when focus moves outside. The panel is positioned against the trigger automatically.

```html preview
<button id="popover-1-trigger" class="btn">Open Popover</button>

<div class="popover" data-sp-popover="toggle: #popover-1-trigger">
  <div class="space-y-1">
    <h4 class="font-medium">Dimensions</h4>
    <p class="text-sm text-muted-foreground">Set the dimensions for the layer.</p>
  </div>
  <div class="mt-3 flex flex-col gap-3">
    <div class="flex items-center gap-4">
      <label class="label w-20 shrink-0">Width</label>
      <input class="input" type="text" value="100%" />
    </div>
    <div class="flex items-center gap-4">
      <label class="label w-20 shrink-0">Height</label>
      <input class="input" type="text" value="25px" />
    </div>
  </div>
</div>
```

## Placement

Set where the popover opens relative to its trigger with the `placement` option (any [Floating UI placement](https://floating-ui.com/docs/computePosition#placement), e.g. `top`, `right`, `bottom-end`).

```html preview
<button id="popover-top-trigger" class="btn">Top</button>

<div class="popover" data-sp-popover="toggle: #popover-top-trigger; placement: top">
  <p class="text-sm">This popover opens above the trigger.</p>
</div>
```

## Hover

Add `mode: hover` to open the popover on hover instead of click. It opens on pointer enter or focus, and closes when the pointer leaves both the trigger and the panel.

```html preview
<button id="popover-hover-trigger" class="btn">Hover me</button>

<div class="popover" data-sp-popover="toggle: #popover-hover-trigger; mode: hover">
  <p class="text-sm">Opened on hover, closes when you leave.</p>
</div>
```

## Options

Set options in the `data-sp-popover` value, separated by semicolons.

| Option      | Type   | Default  | Description                                               |
| ----------- | ------ | -------- | --------------------------------------------------------- |
| `toggle`    | String | —        | Selector for the element that opens the popover           |
| `placement` | String | `bottom` | Position relative to the trigger (Floating UI placement)  |
| `offset`    | Number | `6`            | Gap in pixels between the trigger and the popover        |
| `mode`      | String | `click`        | `click` to toggle on click, `hover` to open on hover     |

## Events

Lifecycle events fire on the popover element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before showing (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before hiding (cancelable)  |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

```js
el.addEventListener("sp-beforeshow", (e) => {
  if (!ready) e.preventDefault(); // veto the open
});
```

## Methods

Get the instance with `sp.popover(el)`, then call its methods:

| Method     | Description                |
| ---------- | -------------------------- |
| `show()`   | Open the popover           |
| `hide()`   | Close the popover          |
| `toggle()` | Open if closed, else close |

```js
const popover = sp.popover(document.querySelector("#my-popover"));

popover.show();
```

## Accessibility

The popover is non-modal, following the WAI-ARIA [disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/): it does not trap focus or block the page. The trigger's `aria-expanded` and `aria-controls` are kept in sync automatically.
