A small label anchored to a trigger, shown on hover or keyboard focus.

## Basic Usage

Add the `tooltip` class to an element with an `id` and a `data-sp-tooltip` attribute with a `toggle` option pointing at the trigger's `id`. It shows on hover or focus and hides when the pointer leaves. The trigger is described by the tooltip automatically.

```html preview
<button id="tooltip-1-trigger" class="btn">Hover me</button>

<div id="tooltip-1" class="tooltip" data-sp-tooltip="toggle: #tooltip-1-trigger">
  Add to library
</div>
```

## Placement

Set where the tooltip opens relative to its trigger with the `placement` option (any [Floating UI placement](https://floating-ui.com/docs/computePosition#placement), e.g. `right`, `bottom`, `left`). Defaults to `top`.

```html preview
<button id="tooltip-right-trigger" class="btn">Right</button>

<div
  id="tooltip-right"
  class="tooltip"
  data-sp-tooltip="toggle: #tooltip-right-trigger; placement: right"
>
  Opens to the right
</div>
```

## Options

Set options in the `data-sp-tooltip` value, separated by semicolons.

| Option      | Type   | Default | Description                                              |
| ----------- | ------ | ------- | -------------------------------------------------------- |
| `toggle`    | String | —       | Selector for the element the tooltip describes           |
| `placement` | String | `top`   | Position relative to the trigger (Floating UI placement) |
| `offset`    | Number | `6`     | Gap in pixels between the trigger and the tooltip        |

## Events

Lifecycle events fire on the tooltip element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp:beforeshow` | Before showing (cancelable) |
| `sp:show`       | Opening                     |
| `sp:shown`      | Open and settled            |
| `sp:beforehide` | Before hiding (cancelable)  |
| `sp:hide`       | Closing                     |
| `sp:hidden`     | Closed                      |

## Methods

Get the instance with `sp.tooltip(el)`, then call its methods:

| Method     | Description                |
| ---------- | -------------------------- |
| `show()`   | Show the tooltip           |
| `hide()`   | Hide the tooltip           |
| `toggle()` | Show if hidden, else hide  |

```js
const tooltip = sp.tooltip(document.querySelector("#my-tooltip"));

tooltip.show();
```

## Accessibility

The tooltip follows the WAI-ARIA [tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/): it sets `role="tooltip"` on itself and `aria-describedby` on the trigger automatically, and shows on focus as well as hover so it works for keyboard users.
