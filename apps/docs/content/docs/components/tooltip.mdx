title: Tooltip
description: An accessible tooltip for Tailwind CSS, shown on hover or focus and anchored to its trigger.
---

A small label anchored to a trigger, shown on hover or keyboard focus.

```html preview
<button id="tooltip-1-trigger" class="btn">Hover me</button>

<div id="tooltip-1" class="tooltip" data-sp-toggle="#tooltip-1-trigger">
  Add to library
</div>
```

## Usage

Add the `tooltip` class to an element and give it an `id`. Give your trigger an `id` too, then point the tooltip at it with `data-sp-toggle`. It shows on hover or focus and hides when the pointer leaves. The trigger is described by the tooltip automatically.

```html
<!-- This is the trigger -->
<button id="my-trigger" class="btn">Hover me</button>

<!-- This is the tooltip -->
<div id="my-tooltip" class="tooltip" data-sp-toggle="#my-trigger">
  Add to library
</div>
```

---

## Examples

### Placement

Set where the tooltip opens relative to its trigger with `data-sp-placement` (any [Floating UI placement](https://floating-ui.com/docs/computePosition#placement), e.g. `right`, `bottom`, `left`). Defaults to `top`.

```html preview
<button id="tooltip-right-trigger" class="btn">Right</button>

<div
  id="tooltip-right"
  class="tooltip"
  data-sp-toggle="#tooltip-right-trigger"
  data-sp-placement="right"
>
  Opens to the right
</div>
```

---

## Options

Set each option with its own `data-sp-*` attribute on the tooltip.

| Attribute           | Type   | Default | Description                                              |
| ------------------- | ------ | ------- | -------------------------------------------------------- |
| `data-sp-toggle`    | String | —       | Selector for the element the tooltip describes           |
| `data-sp-placement` | String | `top`   | Position relative to the trigger (Floating UI placement) |
| `data-sp-offset`    | Number | `6`     | Gap in pixels between the trigger and the tooltip        |

---

## Events

Lifecycle events fire on the tooltip element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before showing (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before hiding (cancelable)  |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

---

## Methods

Get the instance with `sp.tooltip(el)`, then call its methods:

| Method     | Description                |
| ---------- | -------------------------- |
| `show()`   | Show the tooltip           |
| `hide()`   | Hide the tooltip           |
| `toggle()` | Show if hidden, else hide  |

```js
const tooltip = sp.tooltip(document.querySelector("#my-tooltip"));

tooltip.show();
```

---

## Accessibility

The tooltip follows the WAI-ARIA [tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/): it sets `role="tooltip"` on itself and `aria-describedby` on the trigger automatically, and shows on focus as well as hover so it works for keyboard users.
