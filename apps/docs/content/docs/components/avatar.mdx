---
title: Avatar
description: An avatar component for Tailwind CSS with beautiful shadcn/ui styling. Use it to show a user's picture in profiles, comments, and menus, alone or stacked in groups.
---

The avatar shows a user's image in a circle, falling back to initials when the image is missing or fails to load. Avatars stack into groups with an optional overflow count, and a badge can mark status.

```html preview
<span class="avatar">
  <img
    class="avatar-image"
    src="https://cdn.gufo.dev/stockphotos/1c7a7245.webp"
    alt="Sarah Johnson"
  />
  <span class="avatar-fallback">SJ</span>
</span>

<span class="avatar">
  <img
    class="avatar-image"
    src="https://cdn.gufo.dev/stockphotos/a8a338c1.webp"
    alt="Maya Lindberg"
  />
  <span class="avatar-fallback">ML</span>
  <span class="avatar-badge bg-green-600 dark:bg-green-800"></span>
</span>

<span class="avatar-group">
  <span class="avatar">
    <img
      class="avatar-image"
      src="https://cdn.gufo.dev/stockphotos/1c7a7245.webp"
      alt="Sarah Johnson"
    />
    <span class="avatar-fallback">SJ</span>
  </span>
  <span class="avatar">
    <img
      class="avatar-image"
      src="https://cdn.gufo.dev/stockphotos/a8a338c1.webp"
      alt="Maya Lindberg"
    />
    <span class="avatar-fallback">ML</span>
  </span>
  <span class="avatar">
    <img
      class="avatar-image"
      src="https://cdn.gufo.dev/stockphotos/7bd8889a.webp"
      alt="Elin Ryd"
    />
    <span class="avatar-fallback">ER</span>
  </span>
  <span class="avatar-group-count">+3</span>
</span>
```

## Usage

Add the `avatar` class to a wrapper holding the image and the fallback initials. The image wins while it works; when it is missing or fails to load, the fallback shows instead. Give the `<img>` a meaningful `alt`, like the person's name.

| Class                   | Description                                                        |
| ----------------------- | ------------------------------------------------------------------ |
| `avatar`                | Add to the wrapper `<span>`                                        |
| `avatar-sm` `avatar-lg` | Add to `avatar` to change the size                                 |
| `avatar-image`          | Add to the `<img>` inside                                          |
| `avatar-fallback`       | Add to a `<span>` with initials, shown when the image can't be     |
| `avatar-badge`          | Add to a `<span>` inside for a status dot, optionally with an icon |
| `avatar-group`          | Add to a wrapper stacking several avatars                          |
| `avatar-group-count`    | Add to a `<span>` in a group showing the overflow count            |

```html
<span class="avatar">
  <img class="avatar-image" src="/portrait.webp" alt="Sarah Johnson" />
  <span class="avatar-fallback">SJ</span>
</span>
```

## Examples

### Basic

An image with fallback initials behind it.

```html preview
<span class="avatar">

</span>
```

Add `avatar-sm` or `avatar-lg` to change the size.

```html preview

  <span class="avatar avatar-sm">

  </span>

  </span>
  <span class="avatar avatar-lg">
```

### Fallback

When the image is missing or fails to load, the initials take over.

```html preview
<span class="avatar">
  <img class="avatar-image" src="/broken-link.webp" alt="Sarah Johnson" />
  <span class="avatar-fallback">SJ</span>
</span>

<span class="avatar">
  <span class="avatar-fallback">ER</span>
</span>
```

### Badge

Mark status with an `avatar-badge`; color it with utilities.

```html preview
<span class="avatar">
  <img
    class="avatar-image"
    src="https://cdn.gufo.dev/stockphotos/1c7a7245.webp"
    alt="Sarah Johnson"
  />
  <span class="avatar-fallback">SJ</span>
  <span class="avatar-badge bg-green-600 dark:bg-green-800"></span>
</span>
```

### Badge with icon

```html preview

  </span>
</span>
```
