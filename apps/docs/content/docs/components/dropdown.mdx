title: Dropdown

A menu of actions or links anchored to a trigger, with arrow-key navigation.

## Basic Usage

Add the `dropdown` class to an element and a `data-sp-dropdown` attribute with a `toggle` option pointing at the trigger's `id`. Use `dropdown-item` for each entry. The menu opens on click and closes on Escape, an outside click, when focus leaves, or when an item is chosen. Arrow keys move between items and wrap around at both ends.

```html preview
<button id="dropdown-1-trigger" class="btn">Options</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-1-trigger">
  <a href="#" class="dropdown-item">New file</a>
  <a href="#" class="dropdown-item">Copy link</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item">Edit</a>
  <a href="#" class="dropdown-item">Rename</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item">Delete</a>
</div>
```

## Labels

Use `dropdown-label` to group items with a heading.

```html preview
<button id="dropdown-labels-trigger" class="btn">My Account</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-labels-trigger">
  <div class="dropdown-label">Settings</div>
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Billing</a>
  <div class="dropdown-separator"></div>
  <div class="dropdown-label">Help</div>
  <a href="#" class="dropdown-item">Documentation</a>
  <a href="#" class="dropdown-item">Support</a>
</div>
```

## Disabled items

Add `aria-disabled="true"` and `tabindex="-1"` to disable an item. Arrow navigation skips it and choosing it does nothing.

```html preview
<button id="dropdown-disabled-trigger" class="btn">Actions</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-disabled-trigger">
  <a href="#" class="dropdown-item">Edit</a>
  <a href="#" class="dropdown-item" aria-disabled="true" tabindex="-1">Duplicate</a>
  <a href="#" class="dropdown-item">Archive</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item" aria-disabled="true" tabindex="-1">Delete</a>
</div>
```

## Placement

Set where the menu opens relative to its trigger with the `placement` option (any [Floating UI placement](https://floating-ui.com/docs/computePosition#placement)). Defaults to `bottom-start`.

```html preview
<button id="dropdown-end-trigger" class="btn">bottom-end</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-end-trigger; placement: bottom-end">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
</div>

<button id="dropdown-right-trigger" class="btn">right-start</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-right-trigger; placement: right-start">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
</div>
```

## Hover

Add `mode: hover` to open the menu on hover instead of click. It opens on pointer enter or focus, and closes when the pointer leaves both the trigger and the menu.

```html preview
<button id="dropdown-hover-trigger" class="btn">Hover me</button>

<div class="dropdown" data-sp-dropdown="toggle: #dropdown-hover-trigger; mode: hover">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
  <a href="#" class="dropdown-item">Logout</a>
</div>
```

## Options

Set options in the `data-sp-dropdown` value, separated by semicolons.

| Option      | Type   | Default          | Description                                               |
| ----------- | ------ | ---------------- | --------------------------------------------------------- |
| `toggle`    | String | —                | Selector for the element that opens the menu              |
| `placement` | String | `bottom-start`   | Position relative to the trigger (Floating UI placement)  |
| `offset`    | Number | `4`              | Gap in pixels between the trigger and the menu            |
| `mode`      | String | `click`          | `click` to toggle on click, `hover` to open on hover      |
| `item`      | String | `.dropdown-item` | Selector for the entries arrow navigation moves between   |

## Events

Lifecycle events fire on the dropdown element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before showing (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before hiding (cancelable)  |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

```js
el.addEventListener("sp-beforehide", (e) => {
  if (unsavedChanges) e.preventDefault(); // veto the close
});
```

## Methods

Get the instance with `sp.dropdown(el)`, then call its methods:

| Method     | Description                |
| ---------- | -------------------------- |
| `show()`   | Open the menu              |
| `hide()`   | Close the menu             |
| `toggle()` | Open if closed, else close |

```js
const dropdown = sp.dropdown(document.querySelector("#my-dropdown"));

dropdown.show();
```

## Accessibility

The trigger's `aria-expanded` and `aria-controls` are kept in sync automatically, and closing the menu returns focus to the trigger.

The dropdown does not add `role="menu"` or `role="menuitem"` by default. Dropdowns are used for many things in practice (actions, navigation links, forms) and those don't all fit the strict ARIA menu model. If your dropdown is exclusively a list of command actions, you can opt into menu semantics by adding the roles yourself:

```html
<div class="dropdown" data-sp-dropdown="toggle: #my-trigger" role="menu">
  <a href="#" class="dropdown-item" role="menuitem">Edit</a>
  <a href="#" class="dropdown-item" role="menuitem">Delete</a>
</div>
```

| Key               | Action                                            |
| ----------------- | ------------------------------------------------- |
| `Enter` / `Space` | Opens or closes the menu when the trigger is focused |
| `Escape`          | Closes the menu and returns focus to the trigger  |
| `ArrowDown`       | Move to the next item, wrapping to the first      |
| `ArrowUp`         | Move to the previous item, wrapping to the last   |
| `Home` / `End`    | Move to the first or last item                    |
| `Tab`             | Moves focus out of the menu and closes it         |
