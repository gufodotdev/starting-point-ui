title: Dropdown
description: An accessible dropdown menu for Tailwind CSS with full keyboard navigation, anchored to a trigger.
---

A menu of actions or links anchored to a trigger, with arrow-key navigation.

```html preview
<button id="dropdown-1-trigger" class="btn">Options</button>

<div class="dropdown" data-sp-toggle="#dropdown-1-trigger">
  <a href="#" class="dropdown-item">New file</a>
  <a href="#" class="dropdown-item">Copy link</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item">Edit</a>
  <a href="#" class="dropdown-item">Rename</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item">Delete</a>
</div>
```

## Usage

Add the `dropdown` class to an element. Give your trigger an `id`, then point the dropdown at it with `data-sp-toggle`. Use `dropdown-item` for each entry. The menu opens on click and closes on Escape, an outside click, when focus leaves, or when an item is chosen. Arrow keys move between items and wrap around at both ends.

```html
<!-- This is a button toggling the dropdown -->
<button id="my-trigger" class="btn">Options</button>

<!-- This is the dropdown -->
<div class="dropdown" data-sp-toggle="#my-trigger">
  <a href="#" class="dropdown-item">New file</a>
  <a href="#" class="dropdown-item">Copy link</a>
</div>
```

### Labels

Use `dropdown-label` to group items with a heading.

```html preview
<button id="dropdown-labels-trigger" class="btn">My Account</button>

<div class="dropdown" data-sp-toggle="#dropdown-labels-trigger">
  <div class="dropdown-label">Settings</div>
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Billing</a>
  <div class="dropdown-separator"></div>
  <div class="dropdown-label">Help</div>
  <a href="#" class="dropdown-item">Documentation</a>
  <a href="#" class="dropdown-item">Support</a>
</div>
```

### Disabled items

Add `aria-disabled="true"` and `tabindex="-1"` to disable an item. Arrow navigation skips it and choosing it does nothing.

```html preview
<button id="dropdown-disabled-trigger" class="btn">Actions</button>

<div class="dropdown" data-sp-toggle="#dropdown-disabled-trigger">
  <a href="#" class="dropdown-item">Edit</a>
  <a href="#" class="dropdown-item" aria-disabled="true" tabindex="-1">Duplicate</a>
  <a href="#" class="dropdown-item">Archive</a>
  <div class="dropdown-separator"></div>
  <a href="#" class="dropdown-item" aria-disabled="true" tabindex="-1">Delete</a>
</div>
```

### Placement

Set where the menu opens relative to its trigger with `data-sp-placement` (any [Floating UI placement](https://floating-ui.com/docs/computePosition#placement)). Defaults to `bottom-end`.

```html preview
<button id="dropdown-start-trigger" class="btn">bottom-start</button>

<div class="dropdown" data-sp-toggle="#dropdown-start-trigger" data-sp-placement="bottom-start">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
</div>

<button id="dropdown-right-trigger" class="btn">right-start</button>

<div class="dropdown" data-sp-toggle="#dropdown-right-trigger" data-sp-placement="right-start">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
</div>
```

### Hover

Add `data-sp-mode="hover"` to open the menu on hover instead of click. It opens on pointer enter or focus, and closes when the pointer leaves both the trigger and the menu.

```html preview
<button id="dropdown-hover-trigger" class="btn">Hover me</button>

<div class="dropdown" data-sp-toggle="#dropdown-hover-trigger" data-sp-mode="hover">
  <a href="#" class="dropdown-item">Profile</a>
  <a href="#" class="dropdown-item">Settings</a>
  <a href="#" class="dropdown-item">Logout</a>
</div>
```

## Options

Set each option with its own `data-sp-*` attribute on the dropdown.

| Attribute             | Type    | Default          | Description                                              |
| --------------------- | ------- | ---------------- | ------------------------------------------------------- |
| `data-sp-toggle`      | String  | —                | Selector for the element that opens the menu             |
| `data-sp-placement`   | String  | `bottom-end`     | Position relative to the trigger (Floating UI placement) |
| `data-sp-offset`      | Number  | `4`              | Gap in pixels between the trigger and the menu           |
| `data-sp-mode`        | String  | `click`          | `click` to toggle on click, `hover` to open on hover     |
| `data-sp-match-width` | Boolean | `false`          | Match the menu width to the trigger width                |

## Events

Lifecycle events fire on the dropdown element; `before*` events are cancelable.

| Event           | When                        |
| --------------- | --------------------------- |
| `sp-beforeshow` | Before showing (cancelable) |
| `sp-show`       | Opening                     |
| `sp-shown`      | Open and settled            |
| `sp-beforehide` | Before hiding (cancelable)  |
| `sp-hide`       | Closing                     |
| `sp-hidden`     | Closed                      |

```js
el.addEventListener("sp-beforehide", (e) => {
  if (unsavedChanges) e.preventDefault(); // veto the close
});
```

## Methods

Get the instance with `sp.dropdown(el)`, then call its methods:

| Method     | Description                |
| ---------- | -------------------------- |
| `show()`   | Open the menu              |
| `hide()`   | Close the menu             |
| `toggle()` | Open if closed, else close |

```js
const dropdown = sp.dropdown(document.querySelector("#my-dropdown"));

dropdown.show();
```

## Accessibility

The dropdown adheres to the [Menu Button WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) and sets the appropriate roles and properties automatically. Roles you author yourself are left as is.

| Key               | Action                                                |
| ----------------- | ----------------------------------------------------- |
| `Enter` / `Space` | Opens the menu and focuses the first item             |
| `ArrowDown`       | Opens the menu and focuses the first item; inside, move to the next item, wrapping |
| `ArrowUp`         | Opens the menu and focuses the last item; inside, move to the previous item, wrapping |
| `Home` / `End`    | Move to the first or last item                        |
| `Enter` / `Space` | Activates the focused item and closes the menu        |
| `Escape`          | Closes the menu and returns focus to the trigger      |
| `Tab`             | Moves focus out of the menu and closes it             |
