## Usage

Add the `command` class to a container with an [input group](/components/input-group) and a `command-list` inside, then fill the list with `command-item` buttons, grouped under `command-group` when it helps. Typing filters items by their text, groups hide when the filter empties them, and the `command-empty` message appears when nothing matches. Enter or a click runs the highlighted item, firing `sp-select` with it; disable an item with `aria-disabled`.

| Class                  | Description                                             |
| ---------------------- | ------------------------------------------------------- |
| `command`              | Add to the palette container                            |
| `command-list`         | Add to the scrollable list below the input              |
| `command-group`        | Add to a wrapper grouping related items                 |
| `command-label`        | Add to a group's heading line                           |
| `command-item`         | Add to each action, typically a `<button>`              |
| `command-item-checked` | Add to `command-item` to show a trailing check          |
| `command-shortcut`     | Add to a `<span>` with the item's keyboard shortcut     |
| `command-separator`    | Add to a divider between groups                         |
| `command-empty`        | Add to the message shown when nothing matches           |
| `command-dialog`       | Add to a [dialog](/components/dialog) hosting a command |

```html
<div class="command">
  <div class="input-group">
    <input class="input" placeholder="Type a command or search..." />
  </div>
  <div class="command-list">
    <div class="command-empty">No results found.</div>
    <button class="command-item">Calendar</button>
  </div>
</div>
```

## Examples

### Dialog

Host the command in a [dialog](/components/dialog) with `command-dialog` for the classic ⌘K palette; the sr-only title and description name it for screen readers.

```html preview preset=dialog open=.dialog

<dialog class="dialog command-dialog" data-sp-toggle="#command-basic-trigger">
  <div class="dialog-panel">
    <h2 class="dialog-title sr-only">Command Palette</h2>
    <p class="dialog-description sr-only">Search for a command to run...</p>
    <div class="command">
      <div class="input-group">
        <input class="input" placeholder="Type a command or search..." />
        <span class="input-group-addon">
          <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg>
        </span>
      </div>
      <div class="command-list">
        <div class="command-empty">No results found.</div>
        <div class="command-group">
          <div class="command-label">Suggestions</div>
          <button class="command-item">
            <span>Calendar</span>
          </button>
          <button class="command-item">
            <span>Search Emoji</span>
          </button>
          <button class="command-item">
            <span>Calculator</span>
          </button>
        </div>
      </div>
    </div>
  </div>
</dialog>
```

Open it from anywhere with a keyboard shortcut:

```js
const palette = sp.dialog(document.querySelector("#my-command-dialog"));
document.addEventListener("keydown", (e) => {
  if (e.key === "k" && (e.metaKey || e.ctrlKey)) {
    e.preventDefault();
    palette.toggle();
  }
});
```

### Async search

Set `data-sp-filter="false"` when your own code decides what the list contains, like results fetched from a server. The command leaves the items alone while you add and remove them, and keeps wiring roles, highlighting the first result, and toggling the empty message. Groups are yours to manage in this mode; the demo toggles `hidden` on its Results group along with the fake request.

```html preview preset=command
<div
  id="command-async-demo"
  class="command max-w-sm rounded-lg border"
  data-sp-filter="false"
>
  <div class="input-group">
    <input class="input" placeholder="Search components..." />
    <span class="input-group-addon">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m21 21-4.34-4.34"/><circle cx="11" cy="11" r="8"/></svg>
    </span>
  </div>
  <div class="command-list">
    <div class="command-empty visible">No recent searches</div>
    <div class="command-group" hidden>
      <div class="command-label">Results</div>
    </div>
  </div>
</div>

<script>
  const command = document.querySelector("#command-async-demo");
const input = command.querySelector("input");
const group = command.querySelector(".command-group");
const empty = command.querySelector(".command-empty");

const components = [
  "Accordion",
  "Alert",
  "Avatar",
  "Badge",
  "Breadcrumb",
  "Button",
  "Card",
  "Checkbox",
  "Combobox",
  "Command",
  "Dialog",
  "Drawer",
  "Dropdown",
  "Empty",
  "Field",
  "Input",
  "Item",
  "Kbd",
  "Label",
  "Pagination",
  "Popover",
  "Progress",
  "Select",
  "Separator",
  "Sheet",
  "Sidebar",
  "Skeleton",
  "Slider",
  "Switch",
  "Table",
  "Tabs",
  "Textarea",
  "Toast",
  "Tooltip",
];

function render(names) {
  group.querySelectorAll(".command-item").forEach((item) => item.remove());
  group.hidden = names.length === 0;
  for (const name of names) {
    const item = document.createElement("button");
    item.className = "command-item";
    item.textContent = name;
    group.append(item);
  }
}

let timer;
input.addEventListener("input", () => {
  clearTimeout(timer);
  const query = input.value.trim().toLowerCase();
  if (!query) {
    empty.textContent = "No recent searches";
    render([]);
    return;
  }
  empty.textContent = "Searching...";
  timer = setTimeout(() => {
    empty.textContent = "No results found.";
    render(components.filter((name) => name.toLowerCase().includes(query)));
  }, 400);
});
</script>
```

## Options

### Command

Set each option with its own `data-sp-*` attribute on the `command` element.

| Attribute        | Values          | Default |
| ---------------- | --------------- | ------- |
| `data-sp-filter` | `true`, `false` | `true`  |

Set `data-sp-filter="false"` when your own code decides what the list contains, like results from a server search. The command stops matching item text itself and instead tracks the list as it changes: new items get their roles wired, the first one is highlighted, and the empty message toggles automatically. See the [async search example](#async-search).

## JavaScript

### Events

| Event       | When                 |
| ----------- | -------------------- |
| `sp-select` | An item was selected |

```js
document.querySelector(".command").addEventListener("sp-select", (e) => {
  console.log(e.detail.value);
});
```

### Methods

Get the instance with `sp.command(el)`, then call its methods:

| Method          | Description                                             |
| --------------- | ------------------------------------------------------- |
| `filter(query)` | Filter the list as if the user typed `query`            |
| `run(item)`     | Run an item element, firing `sp-select`                 |
| `refresh()`     | Re-wire items and the highlight after changing the list |
