title: Label
description: A label component for Tailwind CSS with beautiful shadcn/ui styling. Use it to name form controls like inputs, checkboxes, and selects.
---

The label names a form control. Clicking it focuses or toggles the control it points at, and screen readers announce it when the control receives focus.

```html preview
<div class="flex gap-2">
  <input type="checkbox" class="checkbox" id="label-demo-terms" />
  <label class="label" for="label-demo-terms">
    Accept terms and conditions
  </label>
</div>
```

## Usage

Add the `label` class to a `<label>` element and connect it to a control with a `for` attribute matching the control's `id`.

| Class   | Description                |
| ------- | -------------------------- |
| `label` | Add to a `<label>` element |

```html
<label class="label" for="name">Name</label>
<input class="input" id="name" type="text" />
```

### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. See the [RTL guide](/guides/rtl) for details.

```html preview dir=rtl
<div id="label-rtl-demo" class="flex gap-2" dir="rtl">
  <input type="checkbox" class="checkbox" id="label-rtl-terms" />
  <label class="label" for="label-rtl-terms" data-i18n="terms">قبول الشروط والأحكام</label>
</div>

<script>
  const translations = {
    ar: { dir: "rtl", terms: "قبول الشروط والأحكام" },
    he: { dir: "rtl", terms: "קבל תנאים והגבלות" },
    en: { dir: "ltr", terms: "Accept terms and conditions" },
  };
  window.addEventListener("message", (e) => {
    const t = translations[e.data?.lang];
    if (e.data?.type !== "sp-language" || !t) return;
    document.getElementById("label-rtl-demo").dir = t.dir;
    document.querySelectorAll("[data-i18n]").forEach((el) => {
      el.textContent = t[el.dataset.i18n];
    });
  });
</script>
```
