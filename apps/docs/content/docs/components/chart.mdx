---
title: Tailwind CSS Charts
description: Beautiful, modern chart component for Tailwind CSS. Use it to turn data into graphs, like revenue trends, site traffic, or a sales breakdown. Easily customizable.
---

Use the chart component to turn data into graphs, like revenue over time, traffic on a dashboard, or a breakdown of sales. For data people read row by row, use a [table](/components/table).

```html preview preset=base

  <div class="chart-viewport aspect-video">
    <svg class="chart-svg" aria-label="Visitors by device">
      <g class="chart-group">
        <path class="chart-bar text-chart-2" data-sp-field="desktop" aria-label="Desktop"></path>
```

## Usage

Add the `chart` class to a wrapper with a height, and put the data in `data-sp-value` as a JSON array of rows. Inside it, add an `<svg>` with the `chart-svg` class and declare what to draw: a mark for each field in its `data-sp-field`, plus any axes and a cursor. Name the svg with `aria-label`, and give each mark and the axis that labels the rows their own `aria-label` to head the columns of the data table screen readers get. A chart without a name is decoration.

| Class                               | Description                                                                         |
| ----------------------------------- | ----------------------------------------------------------------------------------- |
| `chart`                             | Add to the wrapper holding the data                                                 |
| `chart-viewport`                    | Add to a box around the svg when other content sits beside it, like a legend        |
| `chart-svg`                         | Add to the `<svg>` the chart draws into                                             |
| `chart-line`                        | Add to a `<path>` to draw a line through a field                                    |
| `chart-area`                        | Add to a `<path>` to fill the area under a field                                    |
| `chart-point`                       | Add to a `<circle>` to draw a dot on each row                                       |
| `chart-bar`                         | Add to a `<path>` to draw a bar for each row                                        |
| `chart-pie`                         | Add to a `<path>` to draw a slice for each row                                      |
| `chart-label`                       | Add to a `<text>` to write a value on each bar or point                             |
| `chart-group`                       | Add to a `<g>` around bars to set them side by side                                 |
| `chart-stack`                       | Add to a `<g>` around bars or areas to stack them                                   |
| `chart-axis`                        | Add to a `<g>` with `data-sp-axis` set to `x` or `y`                                |
| `chart-axis-tick`                   | Add to a `<text>` in an axis for its labels                                         |
| `chart-axis-grid`                   | Add to a `<line>` in an axis for grid lines                                         |
| `chart-axis-line`                   | Add to a `<line>` in an axis for the axis line                                      |
| `chart-axis-mark`                   | Add to a `<line>` in an axis for tick marks                                         |
| `chart-zero-line`                   | Add to a `<line>` to mark zero when values go below it                              |
| `chart-cursor`                      | Add to a `<line>`, or a `<rect>` with `data-sp-type="area"`, to follow the pointer  |
| `chart-tooltip`                     | Add to a block that shows the hovered row next to the pointer                       |
| `chart-tooltip-heading`             | Add to the tooltip title                                                            |
| `chart-tooltip-item`                | Add to a row of the tooltip                                                         |
| `chart-tooltip-indicator`           | Add to the swatch in a tooltip row                                                  |
| `chart-tooltip-indicator-line`      | Add to `chart-tooltip-indicator` for a bar instead of a square                      |
| `chart-tooltip-indicator-dashed`    | Add to `chart-tooltip-indicator` for a dashed line                                  |
| `chart-value`                       | Add to any element in the chart to show a field of the hovered row                  |
| `chart-legend`                      | Add to a legend item                                                                |
| `chart-legend-indicator`            | Add to the swatch in a legend item                                                  |

```html
<div class="chart aspect-video" data-sp-value='[{"month":"January","desktop":186},{"month":"February","desktop":305}]'>
  <svg class="chart-svg" aria-label="Desktop visitors">
    <path class="chart-line" data-sp-field="desktop"></path>
  </svg>
</div>
```

## Options

### Chart

Set each option with its own `data-sp-*` attribute on the `chart` element.

| Attribute            | Values                            | Default            |
| -------------------- | --------------------------------- | ------------------ |
| `data-sp-value`      | JSON array of rows, or of numbers | `[]`               |
| `data-sp-horizontal` | Boolean                           | `false`            |
| `data-sp-locale`     | BCP 47 locale                     | The nearest `lang` |

```html
<div class="chart" data-sp-horizontal data-sp-locale="de-DE" data-sp-value='[{"month":"January","desktop":186}]'></div>
```

### Svg

| Attribute        | Values                                         | Default |
| ---------------- | ---------------------------------------------- | ------- |
| `data-sp-gutter` | Padding in pixels, one to four values like CSS | `0`     |

### Marks

Set these on `chart-line`, `chart-area`, `chart-point`, and `chart-bar`.

| Attribute        | Values                                           | Default                |
| ---------------- | ------------------------------------------------ | ---------------------- |
| `data-sp-field`  | Field to plot                                    | `value`                |
| `data-sp-curve`  | `smooth` or `none`, on lines and areas           | `smooth`               |
| `data-sp-radius` | Corner radius of a bar, its end then its base    | `4`, or `0` in a stack |
| `data-sp-width`  | Bar thickness, a percentage of the row or pixels | `80%`                  |

Set `data-sp-width` on a `chart-group` or `chart-stack` to size its bars together, and `data-sp-offset="expand"` on a `chart-stack` to fill every row to 100%.

### Label

Set these on a `chart-label`.

| Attribute             | Values                                                       | Default |
| --------------------- | ------------------------------------------------------------ | ------- |
| `data-sp-field`       | Field of the bar or point to label                           | `value` |
| `data-sp-label-field` | Field to show instead of the value                           | None    |
| `data-sp-position`    | `end`, `inside-end`, or `inside-start`                       | `end`   |
| `data-sp-format`      | JSON of `Intl.NumberFormat` or `Intl.DateTimeFormat` options | None    |
| `data-sp-prefix`      | Text before the value                                        | None    |
| `data-sp-suffix`      | Text after the value                                         | None    |

### Pie

| Attribute              | Values                                | Default |
| ---------------------- | ------------------------------------- | ------- |
| `data-sp-field`        | Field that sets each slice's size     | `value` |
| `data-sp-label-field`  | Field that names each slice           | None    |
| `data-sp-inner-radius` | Donut hole, in pixels or a percentage | `0`     |

### Axis

| Attribute             | Values                                                                               | Default                              |
| --------------------- | ------------------------------------------------------------------------------------ | ------------------------------------ |
| `data-sp-axis`        | `x` or `y`                                                                           | `x`                                  |
| `data-sp-field`       | Field that labels the rows                                                           | The row number                       |
| `data-sp-position`    | `top`, `bottom`, `start`, `end`, `left`, or `right`                                  | `bottom` for x, `start` for y        |
| `data-sp-scale`       | `categorical`, `time`, or `linear`                                                   | `time` for dates, else `categorical` |
| `data-sp-tick-count`  | Number of ticks to aim for, or `2` for only the two ends, with the data edge to edge | Fits the space                       |
| `data-sp-tick-start`  | `min` or a number                                                                    | `0`, or below negative values        |
| `data-sp-tick-end`    | `max` or a number                                                                    | The first tick at or above the max   |
| `data-sp-tick-values` | JSON array of numbers                                                                | None                                 |
| `data-sp-tick-prefix` | Text before each label                                                               | None                                 |
| `data-sp-tick-suffix` | Text after each label                                                                | None                                 |
| `data-sp-format`      | JSON of `Intl.NumberFormat` or `Intl.DateTimeFormat` options                         | None                                 |

```html
<g class="chart-axis" data-sp-axis="y" data-sp-tick-prefix="$" data-sp-format='{"notation":"compact"}'>
  <text class="chart-axis-tick"></text>
</g>
```

### Cursor

| Attribute      | Values           | Default |
| -------------- | ---------------- | ------- |
| `data-sp-type` | `line` or `area` | `line`  |

### Value

Set these on a `chart-value`.

| Attribute          | Values                                                       | Default      |
| ------------------ | ------------------------------------------------------------ | ------------ |
| `data-sp-field`    | Field to show                                                | `value`      |
| `data-sp-format`   | JSON of `Intl.NumberFormat` or `Intl.DateTimeFormat` options | None         |
| `data-sp-prefix`   | Text before the value                                        | None         |
| `data-sp-suffix`   | Text after the value                                         | None         |
| `data-sp-fallback` | Text to show while no row is hovered                         | The last row |

## JavaScript

### Methods

Get the instance with `sp.chart(el)`, then call its methods:

| Method              | Description                                       |
| ------------------- | ------------------------------------------------- |
| `setValue(rows)`    | Replace the data and draw the chart again          |
| `setActive(index)`  | Point the chart at a row, or at none with `null`  |

```js
const chart = sp.chart(document.querySelector("#my-chart"));

chart.setValue([{ month: "July", desktop: 214 }]);
```

Changing `data-sp-value` draws the chart again too, so data swapped in by the server needs no script.
