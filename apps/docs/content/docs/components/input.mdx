Use the input component to capture a single line of text, like a name, an email, or a search query. Pair it with a [field](/components/field) for a label and description, and for multi-line text, reach for the [textarea](/components/textarea).

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-demo-api-key">API Key</label>
  <input
    class="input"
    id="input-demo-api-key"
    type="password"
    placeholder="sk-..."
  />
  <p class="field-description">
    Your API key is encrypted and stored securely.
  </p>
</div>
```

## Usage

Add the `input` class to an `<input>` element. It styles all the textual types plus file inputs, and reads validation state from `aria-invalid`.

| Class      | Description                        |
| ---------- | ---------------------------------- |
| `input`    | Add to an `<input>` element        |
| `input-sm` | Add to `input` for a compact field |

```html
<input class="input" type="email" placeholder="Email" />
```

## Examples

### Basic input

A bare input with only a placeholder.

```html preview preset=sm
<input class="input w-full max-w-sm" placeholder="Enter text" />
```

### Input with a label

Wrap the input in a [field](/components/field) with a [label](/components/label) and description.

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-field-username">Username</label>
  <input
    class="input"
    id="input-field-username"
    type="text"
    placeholder="Enter your username"
  />
  <p class="field-description">Choose a unique username for your account.</p>
</div>
```

### Stacked inputs

Stack several fields with a [field group](/components/field).

```html preview preset=base
<div class="field-group w-full max-w-sm">
  <div class="field">
    <label class="label" for="fieldgroup-name">Name</label>
    <input class="input" id="fieldgroup-name" placeholder="Jordan Lee" />
  </div>
  <div class="field">
    <label class="label" for="fieldgroup-email">Email</label>
    <input
      class="input"
      id="fieldgroup-email"
      type="email"
      placeholder="name@example.com"
    />
    <p class="field-description">We'll send updates to this address.</p>
  </div>
  <div class="field field-horizontal">
    <button type="reset" class="btn btn-outline">Reset</button>
    <button type="submit" class="btn">Submit</button>
  </div>
</div>
```

### Disabled

Add `disabled` and the input mutes itself and blocks interaction.

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-demo-disabled">Email</label>
  <input
    class="input"
    id="input-demo-disabled"
    type="email"
    placeholder="Email"
    disabled
  />
  <p class="field-description">This field is currently disabled.</p>
</div>
```

### Invalid

Set `aria-invalid` on the input for the error ring.

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-invalid">Invalid Input</label>
  <input
    class="input"
    id="input-invalid"
    placeholder="Error"
    aria-invalid="true"
  />
  <p class="field-description">This field contains validation errors.</p>
</div>
```

### File input

File inputs get matching button-like styling for the browse control.

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-picture">Picture</label>
  <input class="input" id="input-picture" type="file" />
  <p class="field-description">Select a picture to upload.</p>
</div>
```

### Input with a button

Lay the input out beside a [button](/components/button) with a horizontal field.

```html preview preset=sm
<div class="field field-horizontal w-full max-w-sm">
  <input class="input" type="search" placeholder="Search..." />
  <button class="btn">Search</button>
</div>
```

### Inputs in a grid

```html preview preset=sm

  <div class="field">
    <label class="label" for="input-first-name">First Name</label>
    <input class="input" id="input-first-name" placeholder="Jordan" />
  </div>
  <div class="field">
    <label class="label" for="input-last-name">Last Name</label>
    <input class="input" id="input-last-name" placeholder="Lee" />

```

### Required input

Mark the label and add `required` so the browser enforces the field.

```html preview preset=sm
<div class="field w-full max-w-sm">
  <label class="label" for="input-required">
    Required Field
    <span class="text-destructive">*</span>
  </label>
  <input
    class="input"
    id="input-required"
    placeholder="This field is required"
    required
  />
  <p class="field-description">This field must be filled out.</p>
</div>
```


### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. See the [RTL guide](/guides/rtl) for details.

```html preview preset=sm dir=rtl
<div id="input-rtl-demo" class="field w-full max-w-sm" dir="rtl">
  <label class="label" for="input-rtl-api-key" data-i18n="apiKey">مفتاح API</label>
  <input
    class="input"
    id="input-rtl-api-key"
    type="password"
    placeholder="sk-..."
  />
  <p class="field-description" data-i18n="description">مفتاح API الخاص بك مشفر ومخزن بأمان.</p>
</div>

<script>
  const translations = {
    ar: { dir: "rtl", apiKey: "مفتاح API", description: "مفتاح API الخاص بك مشفر ومخزن بأمان." },
    he: { dir: "rtl", apiKey: "מפתח API", description: "מפתח ה-API שלך מוצפן ונשמר בצורה מאובטחת." },
    en: { dir: "ltr", apiKey: "API Key", description: "Your API key is encrypted and stored securely." },
  };
  window.addEventListener("message", (e) => {
    const t = translations[e.data?.lang];
    if (e.data?.type !== "sp-language" || !t) return;
    document.getElementById("input-rtl-demo").dir = t.dir;
    document.querySelectorAll("[data-i18n]").forEach((el) => {
      el.textContent = t[el.dataset.i18n];
    });
  });
</script>
```
