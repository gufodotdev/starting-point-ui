Use the scrollbar utility to restyle or hide the native scrollbar of any scrollable element, like a sidebar, a code block, or a chat feed. For fading the edges of a scroller, use the [scroll fade](/components/scroll-fade) utility.

  class="scrollbar h-48 w-full max-w-sm overflow-y-auto rounded-lg border p-4 text-sm/6 text-muted-foreground"
>
  <p class="mb-4">
    Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod

## Usage

Add the `scrollbar` class to an element that scrolls and its scrollbars are styled, vertical and horizontal alike. Add `scrollbar-sm` for a thinner thumb in tighter spaces.

| Class            | Description                                               |
| ---------------- | --------------------------------------------------------- |
| `scrollbar`      | Add to a scrollable element to style its scrollbar        |
| `scrollbar-sm`   | Add to `scrollbar` for a thinner variant                  |
| `scrollbar-none` | Add to hide the scrollbar while the element still scrolls |

```html
<div class="scrollbar h-48 overflow-y-auto">Long content</div>
```

## CSS variables

Override the variables per element with an arbitrary property, or for the whole app with a CSS rule.

| Variable             | Default                                     | Description         |
| -------------------- | ------------------------------------------- | ------------------- |
| `--scrollbar-track`  | `transparent`                               | Track color         |
| `--scrollbar-thumb`  | `var(--border)`                             | Thumb color         |
| `--scrollbar-width`  | `0.625rem` (`0.375rem` with `scrollbar-sm`) | Scrollbar thickness |
| `--scrollbar-radius` | `9999px`                                    | Thumb corner radius |

```html
<div class="scrollbar [--scrollbar-thumb:var(--primary)] h-48 overflow-y-auto">
  Long content
</div>
```
