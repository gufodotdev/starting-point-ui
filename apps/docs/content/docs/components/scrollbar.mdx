## Usage

Add the `scrollbar` class to an element that scrolls and its scrollbars are styled, vertical and horizontal alike. Add `scrollbar-sm` for a thinner thumb in tighter spaces.

| Class            | Description                                                   |
| ---------------- | ------------------------------------------------------------- |
| `scrollbar`      | Add to a scrollable element to style its scrollbar            |
| `scrollbar-sm`   | Add to `scrollbar` for a thinner variant                      |
| `scrollbar-none` | Add to hide the scrollbar entirely; the element still scrolls |

```html
<div class="scrollbar h-48 overflow-y-auto">Long content</div>
```

## CSS variables

The scrollbar reads its colors and metrics from component-local variables. Override them per instance with an arbitrary property, or for the whole app with a plain CSS rule.

| Variable             | Default                                     | Description         |
| -------------------- | ------------------------------------------- | ------------------- |
| `--scrollbar-track`  | `transparent`                               | Track color         |
| `--scrollbar-thumb`  | `var(--border)`                             | Thumb color         |
| `--scrollbar-width`  | `0.625rem` (`0.375rem` with `scrollbar-sm`) | Scrollbar thickness |
| `--scrollbar-radius` | `9999px`                                    | Thumb corner radius |

```html
<div class="scrollbar [--scrollbar-thumb:var(--primary)] h-48 overflow-y-auto">
  Long content
</div>
```
