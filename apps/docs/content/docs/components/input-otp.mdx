Use the input OTP component to enter one-time codes, like two-factor login, email verification, or a PIN. For regular text, use an [input](/components/input).

```html preview preset=sm
<label class="input-otp">
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <input
    maxlength="6"
    name="code"
    value="123456"
    inputmode="numeric"
    autocomplete="one-time-code"
    aria-label="One-time code"
  />
</label>
```

## Usage

Add the `input-otp` class to a `<label>` with an empty `<span>` for each character, then an `<input>` whose `maxlength` matches the number of spans, up to eight. Name the input with `aria-label` or a separate label.

| Class                 | Description                               |
| --------------------- | ----------------------------------------- |
| `input-otp`           | Add to the `<label>` holding the boxes    |
| `input-otp-separated` | Add to `input-otp` to set the boxes apart |

```html
<label class="input-otp">
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <input
    name="code"
    maxlength="4"
    autocomplete="one-time-code"
    aria-label="One-time code"
  />
</label>
```

## Examples

### OTP input with a pattern

Add `pattern` and `required` to validate the code on submit, and `inputmode="numeric"` for a number pad on phones.

```html preview preset=sm
<div class="field w-fit">
  <label class="label" for="otp-digits-only">Digits Only</label>
  <label class="input-otp">
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <input
      maxlength="6"
      id="otp-digits-only"
      name="code"
      inputmode="numeric"
      pattern="[0-9]{6}"
      required
    />
  </label>
</div>
```

### Controlled OTP input

Listen for `input` on the input to read the code as it is typed.

```html preview preset=sm
<div id="otp-controlled" class="grid justify-items-center gap-2">
  <label class="input-otp">
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <input maxlength="6" inputmode="numeric" aria-label="One-time code" />
  </label>
  <div class="text-center text-sm" data-otp-message>
    Enter your one-time password.
  </div>
</div>

<script>
  const root = document.getElementById("otp-controlled");
  root.querySelector("input").addEventListener("input", (e) => {
    root.querySelector("[data-otp-message]").textContent = e.target.value
      ? `You entered: ${e.target.value}`
      : "Enter your one-time password.";
  });
</script>
```

```html preview preset=sm
  <span></span>
  <span></span>
  <span></span>
```

```html preview preset=sm
    maxlength="4"

    inputmode="numeric"

  />

```

### Alphanumeric OTP

Leave out `inputmode`, add `spellcheck="false"`, and use a pattern like `[a-zA-Z0-9]{6}` to accept letters and numbers.

```html preview preset=sm
<label class="input-otp">
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <input
    maxlength="6"
    name="code"
    pattern="[a-zA-Z0-9]{6}"
    spellcheck="false"
    aria-label="One-time code"
    required
  />
</label>
```

### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. The code itself always reads left to right. See the [RTL guide](/guides/rtl) for details.

```html preview preset=sm dir=rtl
<div id="input-otp-rtl-demo" class="field w-fit" dir="rtl">
  <label class="label" for="input-otp-rtl" data-i18n="verificationCode">
    رمز التحقق
  </label>
  <label class="input-otp">
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <span></span>
    <input
      maxlength="6"
      id="input-otp-rtl"
      value="123456"
      inputmode="numeric"
    />
  </label>
</div>

<script>
  const translations = {
    ar: { dir: "rtl", verificationCode: "رمز التحقق" },
    he: { dir: "rtl", verificationCode: "קוד אימות" },
    en: { dir: "ltr", verificationCode: "Verification code" },
  };
  window.addEventListener("message", (e) => {
    const t = translations[e.data?.lang];
    if (e.data?.type !== "sp-language" || !t) return;
    document.getElementById("input-otp-rtl-demo").dir = t.dir;
    document.querySelectorAll("[data-i18n]").forEach((el) => {
      el.textContent = t[el.dataset.i18n];
    });
  });
</script>
```

## CSS variables

Set these on the `input-otp` element.

| Variable           | Default                                   | Description               |
| ------------------ | ----------------------------------------- | ------------------------- |
| `--input-otp-size` | `2.25rem`                                 | Width and height of a box |
| `--input-otp-gap`  | `0` (`0.5rem` with `input-otp-separated`) | Space between the boxes   |
