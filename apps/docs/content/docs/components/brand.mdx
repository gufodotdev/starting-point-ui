---
title: Brand
description: A Tailwind CSS brand component for displaying your company or application's logo and name consistently across your interface.
---

The brand is your product's identity block: a logo box paired with a name that renders consistently wherever it goes, from the [navbar](/components/navbar) and [sidebar](/components/sidebar) to footers and login pages.

```html preview
<a href="#" class="brand">
  <span class="brand-logo">
    <i class="font-serif font-bold not-italic">A</i>
  </span>
  <span class="brand-name">Acme Inc.</span>
</a>
```

## Usage

A brand pairs a `brand-logo` with a `brand-name` inside a `brand` row, usually an anchor pointing home. The logo box fits an image, an inline SVG, or any custom content.

| Class            | Description                                                        |
| ---------------- | ------------------------------------------------------------------ |
| `brand`          | Add to the row wrapping the logo and name, usually a link          |
| `brand-logo`     | Add to the logo box; holds an image, SVG, or custom markup         |
| `brand-logo-lg`  | Add to `brand-logo` for tall rows like `sidebar-menu-button-lg`    |
| `brand-name`     | Add to the company or application name                             |
| `brand-text`     | Add to stack the name with a subtitle in a two-line block          |
| `brand-subtitle` | Add to a muted second line under the name                          |

```html
<!-- This is the brand, usually a link pointing home -->
<a href="/" class="brand">
  <!-- The logo box: an image, an inline SVG, or custom markup -->
  <span class="brand-logo">
    <img src="/logo.png" alt="" />
  </span>
  <span class="brand-name">Acme Inc.</span>
</a>
```

## Examples

### Drawn mark

An original SVG glyph on the default box, here a soft diagonal band with a dot.

```html preview
<a href="#" class="brand">
  <span class="brand-logo">
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor">
      <path d="M6.5 16.5 16.5 6.5" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round"/>
      <circle cx="17" cy="17" r="2.5"/>
    </svg>
  </span>
  <span class="brand-name">Starting Point</span>
</a>
```

### Solid circle

A filled circle carrying a simple white glyph. The logo box goes transparent and the SVG becomes the whole mark.

```html preview
<a href="#" class="brand">
  <span class="brand-logo size-7 bg-transparent">
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 28 28" fill="none" class="size-7">
      <circle cx="14" cy="14" r="14" fill="#e11d48"/>
      <path d="M6.5 14h3l2.5-5 4 10 2.5-5h3" stroke="#fff" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round"/>
    </svg>
  </span>
  <span class="brand-name">Pulse</span>
</a>
```

### Two-tone

Offset shapes in a color and its lighter tints add depth without any detail work.


### Monogram

A single well-set letter on the default box. Type does the work.

```html preview
<a href="#" class="brand">
  <span class="brand-logo">
    <i class="font-serif font-bold not-italic">M</i>
  </span>
  <span class="brand-name">Meridian</span>
</a>
```

### With subtitle

Pair a `brand-logo-lg` with a `brand-text` stack to add a muted `brand-subtitle` under the name.

```html preview
<a href="#" class="brand">
  <span class="brand-logo brand-logo-lg">
    <i class="font-serif font-bold not-italic">A</i>
  </span>
  <span class="brand-text">
    <span class="brand-name">Acme Inc.</span>
    <span class="brand-subtitle">Enterprise</span>
  </span>
</a>
```

### Logo only

Display just the logo by omitting the name.

```html preview
<a href="#" class="brand">
  <span class="brand-logo">
    <i class="font-serif font-bold not-italic">A</i>
  </span>
  <span class="sr-only">Acme Inc.</span>
</a>
```

## Accessibility

The brand is usually a link, so give it an accessible name. The visible `brand-name` provides one automatically; for a logo-only brand, keep the name in the markup with an `sr-only` class, as in the example above.

When the logo is an image, use an empty `alt=""` if the name is visible beside it, so screen readers do not announce the brand twice. For a logo-only image brand, put the name in the `alt` text instead.
