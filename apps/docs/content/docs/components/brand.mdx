description: Beautiful, modern brand component for Tailwind CSS. Use it to show your logo and product name, like in a sidebar, a navbar, or a footer. Easily customizable.
---

Use the brand component to show your logo and product name, like in a sidebar header, a navbar, or a footer. For a person's picture instead, use an [avatar](/components/avatar).

```html preview preset=sm
<a href="#" class="brand">
  <span class="brand-logo">
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor"><path d="M6.5 16.5 16.5 6.5" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round"/><circle cx="17" cy="17" r="2.5"/></svg>
  </span>
  <span class="brand-name">Starting Point</span>
</a>
```

## Usage

Add the `brand` class to the link pointing home. Inside it, put the logo in a `brand-logo` box and the name in a `brand-name` span. The box takes a letter, an inline svg, or an `<img>`. Leave the image's `alt` empty when the name shows beside it, so screen readers do not [read it twice](https://www.w3.org/WAI/tutorials/images/functional/).

| Class            | Description                                                        |
| ---------------- | ------------------------------------------------------------------ |
| `brand`          | Add to the row wrapping the logo and name, usually a link home     |
| `brand-logo`     | Add to the logo box holding a letter, an inline svg, or an `<img>` |
| `brand-logo-lg`  | Add to `brand-logo` for the taller box of large rows               |
| `brand-text`     | Add to a wrapper stacking the name and a subtitle                  |
| `brand-name`     | Add to the company or product name                                 |
| `brand-subtitle` | Add to the muted second line under the name                        |

```html
<a href="/" class="brand">
  <span class="brand-logo">
    <img src="/logo.png" alt="" />
  </span>
  <span class="brand-name">Acme Inc.</span>
</a>
```

### Image logo

An `<img>` shows as it is, without the box. For dark mode, flip a monochrome mark with `dark:invert`, or pair a `dark:hidden` image with a `hidden dark:block` one.

```html preview preset=sm
<a href="#" class="brand">
  <span class="brand-logo">
    <img src="/logo.svg" alt="" class="dark:invert" />
  </span>
  <span class="brand-name">Starting Point</span>
</a>
```

### Brand with subtitle

Pair `brand-logo-lg` with a `brand-text` stack to add a `brand-subtitle` under the name.

```html preview preset=sm
<a href="#" class="brand">
  <span class="brand-logo brand-logo-lg">
    <i class="font-serif font-bold not-italic">A</i>
  </span>
  <span class="brand-text">
    <span class="brand-name">Acme Inc.</span>
    <span class="brand-subtitle">Enterprise</span>
  </span>
</a>
```

### Logo only

Leave the name out of view but keep it in an `sr-only` span, so the link keeps its [accessible name](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html).

```html preview preset=sm
<a href="#" class="brand">
  <span class="brand-logo">
    <i class="font-serif font-bold not-italic">A</i>
  </span>
  <span class="sr-only">Acme Inc.</span>
</a>
```

### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. See the [RTL guide](/guides/rtl) for details.

```html preview preset=sm dir=rtl
<div id="brand-rtl-demo" dir="rtl" class="flex flex-wrap items-center justify-center gap-8">
  <a href="#" class="brand">
    <span class="brand-logo">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor"><path d="M6.5 16.5 16.5 6.5" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round"/><circle cx="17" cy="17" r="2.5"/></svg>
    </span>
    <span class="brand-name" data-i18n="name">شركة أكمي</span>
  </a>

  <a href="#" class="brand">
    <span class="brand-logo brand-logo-lg">
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor"><path d="M6.5 16.5 16.5 6.5" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round"/><circle cx="17" cy="17" r="2.5"/></svg>
    </span>
    <span class="brand-text">
      <span class="brand-name" data-i18n="name">شركة أكمي</span>
      <span class="brand-subtitle" data-i18n="plan">المؤسسة</span>
    </span>
  </a>
</div>

<script>
  const translations = {
    ar: { dir: "rtl", name: "شركة أكمي", plan: "المؤسسة" },
    he: { dir: "rtl", name: "אקמי בע״מ", plan: "ארגוני" },
    en: { dir: "ltr", name: "Acme Inc.", plan: "Enterprise" },
  };
  window.addEventListener("message", (e) => {
    const t = translations[e.data?.lang];
    if (e.data?.type !== "sp-language" || !t) return;
    document.getElementById("brand-rtl-demo").dir = t.dir;
    document.querySelectorAll("[data-i18n]").forEach((el) => {
      el.textContent = t[el.dataset.i18n];
    });
  });
</script>
```
