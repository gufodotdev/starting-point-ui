## Usage

Add the `tray` class to a wrapper and put the cards, list, or table you want to group in a `tray-content`. Add a `tray-header` above it for a title and actions, and a `tray-footer` below it for a note or a link.

| Class              | Description                                                                 |
| ------------------ | --------------------------------------------------------------------------- |
| `tray`             | Add to the wrapper, a tinted surface                                        |
| `tray-sm`          | Add to `tray` for a smaller title and a tighter header and footer           |
| `tray-header`      | Add to the row above the content, holding a title and actions               |
| `tray-title`       | Add to a heading in the header                                              |
| `tray-description` | Add to a paragraph under the title                                          |
| `tray-icon`        | Add to an element before the title text to frame an icon                    |
| `tray-content`     | Add to the section holding cards, an item group, a table, or a dialog panel |
| `tray-footer`      | Add to the row below the content, for a note or a link                      |

```html
<div class="tray">
  <div class="tray-header">
    <h3 class="tray-title">Title</h3>
  </div>
  <div class="tray-content">
    <div class="card">...</div>
  </div>
  <div class="tray-footer">Footer</div>
</div>
```

### Tray in a dialog

Put a tray in the `dialog` and the `dialog-panel` in its `tray-content` to frame the dialog.

```html preview preset=lg open=.dialog
<button id="tray-dialog-trigger" class="btn btn-outline">Delete project</button>

<dialog class="dialog" data-sp-toggle="#tray-dialog-trigger">
  <div class="tray max-w-md">
    <div class="tray-content">
      <div class="dialog-panel">
        <div class="dialog-header">
          <h2 class="dialog-title">Delete project</h2>
          <p class="dialog-description">
            This permanently deletes the project and all of its data. This
            cannot be undone.
          </p>
        </div>
        <div class="dialog-footer">
          <button class="btn btn-outline" data-sp-dismiss>Cancel</button>
          <button class="btn btn-destructive" data-sp-dismiss>
            Delete project
          </button>
        </div>
      </div>
    </div>
  </div>
</dialog>
```

### RTL

Add `dir="rtl"` to any parent element, typically `<html>`, to render right-to-left. See the [RTL guide](/guides/rtl) for details.

```html preview preset=sm dir=rtl

  <div class="tray-header">
    <h3 class="tray-title" data-i18n="label">التسجيلات</h3>
    <button
      class="btn btn-ghost btn-icon btn-xs text-muted-foreground"
      aria-label="More"
    >
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="1"/><circle cx="19" cy="12" r="1"/><circle cx="5" cy="12" r="1"/></svg>
    </button>
  </div>
  <div class="tray-content">
    <div class="card">
      <div class="card-content grid gap-1">
        <span class="text-3xl font-semibold tabular-nums">1,769</span>
        <span class="flex items-center gap-1.5 text-muted-foreground">
          <span class="font-medium text-emerald-600 dark:text-emerald-400">

          </span>
          <span data-i18n="compare">مقارنة بالشهر الماضي</span>
        </span>
      </div>
    </div>
  </div>

<script>
  const translations = {
  ar: { dir: "rtl", label: "التسجيلات", compare: "مقارنة بالشهر الماضي" },
  he: { dir: "rtl", label: "הרשמות", compare: "לעומת החודש שעבר" },
  en: { dir: "ltr", label: "Signups", compare: "vs last month" },
};
window.addEventListener("message", (e) => {
  const t = translations[e.data?.lang];
  if (e.data?.type !== "sp-language" || !t) return;
  document.getElementById("tray-rtl-demo").dir = t.dir;
  document.querySelectorAll("[data-i18n]").forEach((el) => {
    el.textContent = t[el.dataset.i18n];
  });
});
</script>
```

## CSS variables

Four variables set the spacing of the tray and the ring and shadow of what sits inside. Override them per tray with an arbitrary property, or for the whole app with a CSS rule.

| Variable         | Default               | Description                                                    |
| ---------------- | --------------------- | -------------------------------------------------------------- |
| `--tray-padding` | `0.375rem`            | Gap between the tray edge and what sits inside                 |
| `--tray-gap`     | `0.375rem`            | Gap between the parts and items inside                         |
| `--tray-ring`    | `--foreground` at 10% | Ring color of the cards, item groups, and dialog panels inside |
| `--tray-shadow`  | A soft shadow         | Shadow of the cards, item groups, and dialog panels inside     |

```css
.tray {
  border-color: transparent;
  --tray-padding: --spacing(1);
  --tray-shadow: var(--shadow-xs);
}
```
